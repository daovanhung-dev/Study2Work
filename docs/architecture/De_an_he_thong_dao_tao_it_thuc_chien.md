# Study2Work Study Product Architecture Brief

This document is a Study-only product architecture brief. It supersedes the older broad proposal.

## Product Focus

Study2Work helps learners move through:

```text
Learn -> Practice -> Assess -> Improve -> Collaborate
```

The approved implementation focuses on measurable Study outcomes: structured learning, practical assessment, mentor feedback, project teamwork, AI learning assistance, community participation and platform governance.

## Value Pillars

| Pillar | Meaning |
|---|---|
| Structured learning | Learners follow published paths, lessons and live sessions. |
| Practice evidence | Quizzes, assignments, labs and project tasks create evidence. |
| Assessment quality | Rubrics, grading and mentor review drive skill matrix updates. |
| Teamwork | Projects, teams, sprints and tasks model practical collaboration. |
| Guided improvement | Dashboards, feedback, notifications and AI suggestions help learners continue. |
| Governance | Admin, settings, audit, moderation and analytics keep the platform controlled. |

## Phases

| Phase | Focus |
|---|---|
| S1 | Identity, profile, baseline skills and learning-path onboarding. |
| S2 | Lesson progress, quiz, assignment submission and grading foundation. |
| S3 | Mentor review, rubric feedback and skill matrix. |
| S4 | Project teamwork, task workflow and project submission. |
| S5 | AI learning support, notification, community and admin/platform governance. |
