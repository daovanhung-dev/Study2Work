# ADM-CONTENT-ARCHIVE-001 — Lưu trữ nội dung

| Thuộc tính | Giá trị |
| --- | --- |
| Method | `POST` |
| Endpoint | `/api/v1/admin/content/{contentType}/{contentId}/archive` |
| Module | 10. Admin quản trị nội dung |
| Access | Bearer JWT |
| Actor | Content Admin, Admin, Super Admin |
| Operation | WRITE |

## Mục tiêu

Lưu trữ nội dung. Không hard delete khi đã có lịch sử học
