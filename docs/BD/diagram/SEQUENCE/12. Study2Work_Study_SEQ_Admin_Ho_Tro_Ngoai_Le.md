# SEQ - Admin Ho Tro Ngoai Le Lo Trinh va Tai Khoan

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant Learner as Learner
    participant Web as Study Web
    participant API as Study API
    participant Support as Learner Support Service
    participant Progress as Progress Service
    participant Account as Account Service
    participant DB as Study DB
    participant Audit as Audit Service
    participant Notify as Notification Service
    participant Admin as Admin

    Learner->>Web: Gui yeu cau doi/reset/huy lo trinh
    Web->>API: POST /api/v1/support-requests
    API->>Support: Validate active path and reason
    Support->>DB: Create support request OPEN
    API-->>Web: Request created

    Admin->>API: GET /api/v1/admin/learners/{learnerId}/support-profile
    API->>Support: Load account, onboarding, progress, history
    Support->>DB: Query learner support profile
    API-->>Admin: Support profile

    Admin->>API: POST /api/v1/admin/support-requests/{requestId}/resolve
    API->>Support: Validate decision and risky action reason
    alt Reset/cancel/switch path
        Support->>Progress: Apply exception without creating two ACTIVE paths
        Progress->>DB: Update enrollment/progress
    else Suspend/restore account
        Support->>Account: Update account status
        Account->>DB: Set SUSPENDED/ACTIVE
    end
    Support->>Audit: Write before/after and reason
    Support->>Notify: Notify learner result
    API-->>Admin: Resolve response
```

## API duoc goi

### POST `/api/v1/support-requests`

Request:

```json
{
  "type": "CHANGE_LEARNING_PATH",
  "currentLearningPathId": "uuid",
  "targetLearningPathId": "uuid",
  "reason": "Em chon sai lo trinh ngay tu dau.",
  "note": "Muon doi sang Frontend."
}
```

Response:

```json
{
  "success": true,
  "businessCode": "SUPPORT_REQUEST_CREATED",
  "message": "Support request created.",
  "data": {
    "requestId": "uuid",
    "status": "OPEN"
  },
  "meta": {},
  "traceId": "uuid"
}
```

### POST `/api/v1/admin/support-requests/{requestId}/resolve`

Request:

```json
{
  "decision": "APPROVED",
  "action": "SWITCH_LEARNING_PATH",
  "targetLearningPathId": "uuid",
  "adminReason": "Hoc vien chon sai lo trinh trong 24h dau.",
  "notifyLearner": true
}
```

Response:

```json
{
  "success": true,
  "businessCode": "SUPPORT_REQUEST_RESOLVED",
  "message": "Support request resolved.",
  "data": {
    "requestId": "uuid",
    "status": "RESOLVED",
    "appliedAction": "SWITCH_LEARNING_PATH",
    "auditLogId": "uuid"
  },
  "meta": {},
  "traceId": "uuid"
}
```

## Ghi chu

- Reset/huy/chuyen lo trinh can canh bao tac dong va ly do.
- Suspend account chan hoc, nop bai va link Zalo rieng tu.
