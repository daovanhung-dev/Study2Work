# SEQ - Bao Cao va Canh Bao Van Hanh

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant Admin as Admin
    participant Web as Admin Web
    participant API as Study API
    participant Report as Reporting Service
    participant DB as Study DB

    Admin->>Web: Mo dashboard van hanh
    Web->>API: GET /api/v1/admin/reports/overview?from=&to=&pathId=&courseId=
    API->>Report: Check permission and aggregate metrics
    Report->>DB: Query account, onboarding, progress, exercise, community facts
    DB-->>Report: Aggregated data
    Report-->>API: Overview metrics without unnecessary PII
    API-->>Web: Report response

    Admin->>Web: Mo canh bao van hanh
    Web->>API: GET /api/v1/admin/reports/alerts
    API->>Report: Calculate thresholds
    Report->>DB: Query drop-off, failed exercises, Zalo reports, review backlog
    API-->>Web: Alert list
```

## API duoc goi

### GET `/api/v1/admin/reports/overview`

Request:

```json
{
  "query": {
    "from": "2026-07-01",
    "to": "2026-07-31",
    "learningPathId": "uuid",
    "courseId": null
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "ADMIN_REPORT_OVERVIEW_LOADED",
  "message": "Overview report loaded.",
  "data": {
    "newAccounts": 120,
    "verificationRate": 0.82,
    "onboardingCompletionRate": 0.74,
    "activatedLearners": 68,

    "filters": {
      "from": "2026-07-01",

}
```
