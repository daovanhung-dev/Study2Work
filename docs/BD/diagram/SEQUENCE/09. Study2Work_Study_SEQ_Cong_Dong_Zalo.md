# SEQ - Mo Link Zalo va Bao Cao Cong Dong

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant U as Learner
    participant Web as Study Web
    participant API as Study API
    participant Community as Community Service
    participant DB as Study DB
    participant Moderator as Moderator / Admin

    U->>Web: Mo dashboard/lo trinh/khoa hoc
    Web->>API: GET /api/v1/community-groups?scopeType=&scopeId=
    API->>Community: Check learner access to scope
    Community->>DB: Load active groups and permissions
    API-->>Web: Groups with join availability

    U->>Web: Bam tham gia nhom
    Web->>API: POST /api/v1/community-groups/{groupId}/open-link
    API->>Community: Require rules confirmation
    Community->>DB: Record CommunityJoinEvent
    API-->>Web: Join link
    Web-->>U: Open external Zalo link

    opt Bao cao van de
        U->>Web: Bao cao link hong/spam
        Web->>API: POST /api/v1/community-groups/{groupId}/reports
        API->>Community: Create report
        Community->>DB: Save report for Moderator/Admin
        Moderator->>API: PATCH /api/v1/admin/community-groups/{groupId}
        API->>Community: Pause/hide/update group
        Community->>DB: Update status
    end
```

## API duoc goi

### POST `/api/v1/community-groups/{groupId}/open-link`

Request:

```json
{
  "path": {
    "groupId": "uuid"
  },
  "body": {
    "confirmedRules": true,
    "sourceScreen": "LEARNING_PATH_DETAIL"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "COMMUNITY_LINK_OPENED",
  "message": "Community link is ready.",
  "data": {
    "groupId": "uuid",
    "joinLink": "https://zalo.me/g/example",
    "eventId": "uuid",
    "meaning": "LINK_OPENED_ONLY"
  },
  "meta": {},
  "traceId": "uuid"
}
```

### POST `/api/v1/community-groups/{groupId}/reports`

Request:

```json
{
  "reason": "BROKEN_LINK",
  "description": "Link khong mo duoc."
}
```

Response:

```json
{
  "success": true,
  "businessCode": "COMMUNITY_REPORT_CREATED",
  "message": "Community report created.",
  "data": {
    "reportId": "uuid",
    "status": "OPEN"
  },
  "meta": {},
  "traceId": "uuid"
}
```

## Ghi chu

- `joinLink` chi tra ve khi hoc vien du quyen va da xac nhan quy tac.
- Study khong dong bo thanh vien/tin nhan Zalo trong V1.
