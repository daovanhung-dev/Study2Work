# SEQ - Hoan Thanh Khoa Hoc va Lo Trinh

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant System as Progress Service
    participant DB as Study DB
    participant Path as Learning Path Service
    participant Notify as Notification Service
    participant U as Learner

    System->>DB: Load required lessons/exercises in chapter/course/path
    DB-->>System: Completion inputs
    System->>System: Recalculate lesson, chapter, course progress
    alt Course conditions met
        System->>DB: Mark CourseEnrollment COMPLETED
        System->>Path: Request next course unlock
        Path->>DB: Set next CourseEnrollment AVAILABLE
        Notify-->>U: Course completed notification
    else Course incomplete
        System-->>U: Return remaining required items
    end

    System->>DB: Check all required courses in active path
    alt Path conditions met
        System->>DB: Mark LearningPathEnrollment COMPLETED
        Path->>DB: Open right to activate next path
        Notify-->>U: Path completed summary
    else Path incomplete
        System-->>U: Return next required action
    end
```

## API duoc goi

### GET `/api/v1/progress/summary`

Request:

```json
{
  "query": {
    "learningPathEnrollmentId": "uuid"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "PROGRESS_SUMMARY_LOADED",
  "message": "Progress summary loaded.",
  "data": {
    "learningPathEnrollmentId": "uuid",
    "pathStatus": "ACTIVE",
    "pathProgressPercent": 85,
    "courses": [
      {
        "courseId": "uuid",
        "status": "COMPLETED",
        "progressPercent": 100
      }
    ],
    "remainingRequiredItems": [
      {
        "type": "EXERCISE",
        "id": "uuid",
        "title": "Final lab"
      }
    ]
  },
  "meta": {},
  "traceId": "uuid"
}
```

### POST `/api/v1/progress/recalculate`

Request:

```json
{
  "learningPathEnrollmentId": "uuid",
  "trigger": {
    "type": "LESSON_COMPLETED",
    "id": "uuid"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "PROGRESS_RECALCULATED",
  "message": "Progress recalculated.",
  "data": {
    "courseStatusChanged": true,
    "completedCourseIds": ["uuid"],
    "pathStatus": "COMPLETED",
    "nextPathActivationAllowed": true
  },
  "meta": {},
  "traceId": "uuid"
}
```
