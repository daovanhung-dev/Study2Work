# SEQ - Admin Quan Tri Noi Dung va Xuat Ban

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant Admin as Content Admin / Admin
    participant Web as Admin Web
    participant API as Study API
    participant Content as Content Admin Service
    participant DB as Study DB
    participant Audit as Audit Service
    participant Notify as Notification Service

    Admin->>Web: Tao/sua lo trinh/khoa/chuong/bai/tai lieu/bai tap
    Web->>API: POST/PUT /api/v1/admin/content/*
    API->>Content: Validate source, usage rights, required conditions
    Content->>DB: Save DRAFT/UPDATED content
    API-->>Web: Saved response

    Admin->>Web: Kiem tra truoc xuat ban
    Web->>API: POST /api/v1/admin/content/{type}/{id}/pre-publish-check
    API->>Content: Run checklist and impact analysis
    Content->>DB: Load content graph and affected learners
    API-->>Web: Checklist result

    Admin->>Web: Xuat ban / luu tru / cap nhat quan trong
    Web->>API: POST /api/v1/admin/content/{type}/{id}/publish
    API->>Content: Apply publish/archive/update
    Content->>DB: Update publish status
    Content->>Audit: Audit action with before/after
    opt Important update
        Content->>Notify: Notify affected learners
    end
    API-->>Web: Publish response
```

## API duoc goi

### POST `/api/v1/admin/content/{type}/{id}/pre-publish-check`

Request:

```json
{
  "path": {
    "type": "COURSE",
    "id": "uuid"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "CONTENT_PRE_PUBLISH_CHECK_COMPLETED",
  "message": "Pre-publish check completed.",
  "data": {
    "passed": false,
    "issues": [
      {
        "code": "MISSING_COMPLETION_RULE",
        "message": "Required lesson must have completion condition."
      }
    ],
    "affectedLearnerCount": 0
  },
  "meta": {},
  "traceId": "uuid"
}
```

### POST `/api/v1/admin/content/{type}/{id}/publish`

Request:

```json
{
  "path": {
    "type": "COURSE",
    "id": "uuid"
  },
  "body": {
    "targetStatus": "PUBLISHED",
    "changeType": "IMPORTANT_UPDATE",
    "reason": "Cap nhat dieu kien hoan thanh va tai lieu moi.",
    "notifyAffectedLearners": true
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "CONTENT_PUBLISHED",
  "message": "Content published.",
  "data": {
    "contentType": "COURSE",
    "id": "uuid",
    "publishStatus": "PUBLISHED",
    "auditLogId": "uuid",
    "notificationBatchId": "uuid"
  },
  "meta": {},
  "traceId": "uuid"
}
```

## Ghi chu

- Publish/archive/thay doi dieu kien hoan thanh phai audit.
- Noi dung khong ro nguon/quyen su dung khong duoc publish.
