# SEQ - RBAC va Audit Log

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant Actor as User / Admin
    participant Web as Study Web
    participant API as Study API
    participant Authz as Authorization Service
    participant Domain as Domain Service
    participant Audit as Audit Service
    participant DB as Study DB

    Actor->>Web: Thuc hien hanh dong
    Web->>API: API request with token
    API->>Authz: Check role, permission, ownership, business state
    Authz->>DB: Load user roles and target state
    alt Denied
        Authz-->>API: Permission/business denial
        API-->>Web: Error response
    else Allowed
        API->>Domain: Execute use case
        Domain->>DB: Apply state change
        alt Audit required
            Domain->>Audit: Write audit action
            Audit->>DB: Persist actor, role, target, before/after, reason
        end
        API-->>Web: Success response
    end

    Actor->>Web: Xem audit log
    Web->>API: GET /api/v1/admin/audit-logs
    API->>Authz: Check audit.read
    API->>Audit: Search logs by filter
    Audit->>DB: Query audit logs
    API-->>Web: Audit log response
```

## API duoc goi

### GET `/api/v1/admin/audit-logs`

Request:

```json
{
  "query": {
    "actorId": "uuid",
    "targetType": "LEARNING_PATH_ENROLLMENT",
    "targetId": "uuid",
    "action": "RESET_PROGRESS",
    "from": "2026-07-01",
    "to": "2026-07-31",
    "page": 1,
    "pageSize": 20
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "AUDIT_LOGS_LISTED",
  "message": "Audit logs loaded.",
  "data": [
    {
      "id": "uuid",
      "actorId": "uuid",
      "actorRole": "ADMIN",
      "action": "RESET_PROGRESS",
      "targetType": "LEARNING_PATH_ENROLLMENT",
      "targetId": "uuid",
      "beforeValue": {
        "status": "ACTIVE",
        "progressPercent": 42
      },
      "afterValue": {
        "status": "RESET_BY_ADMIN",
        "progressPercent": 0
      },
      "reason": "Yeu cau hop le cua hoc vien.",
      "createdAt": "2026-07-05T10:00:00Z"
    }
  ],
  "meta": {
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 1
    }
  },

}
```

### Error envelope khi bi tu choi quyen

```json
{
  "success": false,
  "businessCode": "RBAC_PERMISSION_DENIED",
  "message": "You do not have permission to perform this action.",
  "errors": [
    {
      "field": "permission",
      "reason": "audit.read is required"
    }
  ],
  "traceId": "uuid"
}
```
