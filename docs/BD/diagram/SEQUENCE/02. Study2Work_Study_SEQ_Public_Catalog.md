# SEQ - Public Catalog va Bai Hoc Mau

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant U as Guest / Learner
    participant Web as Study Web
    participant API as Study API
    participant Catalog as Catalog Service
    participant Content as Content Service
    participant DB as Study DB

    U->>Web: Mo danh sach lo trinh/khoa hoc
    Web->>API: GET /api/v1/catalog/learning-paths?keyword=&level=&goal=
    API->>Catalog: Search published public paths
    Catalog->>DB: Query PUBLISHED and public-visible records
    DB-->>Catalog: Paths
    Catalog-->>API: Paths + learnerState if signed in
    API-->>Web: Standard response
    Web-->>U: Hien thi danh sach va trang thai ca nhan

    U->>Web: Mo chi tiet khoa hoc/lo trinh
    Web->>API: GET /api/v1/catalog/courses/{slug}
    API->>Catalog: Load public detail
    Catalog->>DB: Query course, chapters, sample lessons
    DB-->>Catalog: Public detail
    Catalog-->>API: Detail payload
    API-->>Web: Standard response

    opt Mo bai hoc mau
        U->>Web: Chon bai hoc mau
        Web->>API: GET /api/v1/catalog/sample-lessons/{lessonId}
        API->>Content: Check samplePublic and material visibility
        Content->>DB: Load allowed sample content
        DB-->>Content: Sample content
        Content-->>API: Sample lesson payload
        API-->>Web: Standard response
        Web-->>U: Hien thi bai hoc mau, khong tao tien do
    end
```

## API duoc goi

### GET `/api/v1/catalog/learning-paths`

Request:

```json
{
  "query": {
    "keyword": "frontend",
    "goal": "frontend",
    "level": "BEGINNER",
    "durationMaxHours": 80,
    "page": 1,
    "pageSize": 20
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "CATALOG_LEARNING_PATHS_LISTED",
  "message": "Learning paths loaded.",
  "data": [
    {
      "id": "uuid",
      "slug": "frontend-developer",
      "title": "Frontend Developer",
      "summary": "Lo trinh frontend cho nguoi moi.",
      "level": "BEGINNER",
      "estimatedHours": 80,
      "courseCount": 5,
      "publicStatus": "PUBLISHED",
      "learnerState": "NOT_JOINED"
    }
  ],
  "meta": {
    "pagination": {
      "page": 1,
      "pageSize": 20,
      "total": 1
    }
  },
  "traceId": "uuid"
}
```

### GET `/api/v1/catalog/sample-lessons/{lessonId}`

Request:

```json
{
  "path": {
    "lessonId": "uuid"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "CATALOG_SAMPLE_LESSON_LOADED",
  "message": "Sample lesson loaded.",
  "data": {
    "lessonId": "uuid",
    "title": "Bien va kieu du lieu",
    "samplePublic": true,
    "contentBlocks": [
      {
        "type": "VIDEO",
        "title": "Video gioi thieu",
        "url": "https://example.com/sample.mp4"
      }
    ],
    "materials": []
  },
  "meta": {},
  "traceId": "uuid"
}
```

## Ghi chu

- Guest khong tao tien do khi xem bai hoc mau.
