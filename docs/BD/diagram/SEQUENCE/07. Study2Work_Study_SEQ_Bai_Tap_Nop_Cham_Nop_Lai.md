# SEQ - Bai Tap, Nop Bai, Cham Bai va Nop Lai

## Bieu do

```mermaid
sequenceDiagram
    autonumber
    participant U as Learner
    participant Web as Study Web
    participant API as Study API
    participant Exercise as Exercise Service
    participant Progress as Progress Service
    participant Reviewer as Admin / Mentor
    participant DB as Study DB
    participant Notify as Notification Service

    U->>Web: Mo bai tap
    Web->>API: GET /api/v1/exercises/{exerciseId}
    API->>Exercise: Check access and load prompt
    Exercise->>DB: Load exercise and latest submission
    API-->>Web: Exercise detail

    U->>Web: Luu nhap hoac nop bai
    Web->>API: POST /api/v1/exercises/{exerciseId}/submissions
    API->>Exercise: Validate required submission fields
    Exercise->>DB: Create submission DRAFT or SUBMITTED
    alt Quiz auto grade
        Exercise->>DB: Grade and set PASSED/FAILED
        Exercise->>Progress: Update required exercise condition if PASSED
    else Manual review
        Exercise->>DB: Set UNDER_REVIEW
        Exercise->>Notify: Notify reviewer queue
    end
    API-->>Web: Submission result

    opt Manual review
        Reviewer->>API: PATCH /api/v1/admin/exercise-submissions/{submissionId}/review
        API->>Exercise: Save score, feedback, result
        Exercise->>DB: Update PASSED/NEEDS_REVISION/FAILED
        Exercise->>Progress: Update progress if PASSED
        Exercise->>Notify: Notify learner result
    end
```

## API duoc goi

### POST `/api/v1/exercises/{exerciseId}/submissions`

Request:

```json
{
  "path": {
    "exerciseId": "uuid"
  },
  "body": {
    "mode": "SUBMIT",
    "answers": [
      {
        "questionId": "uuid",
        "selectedOptionIds": ["uuid"]
      }
    ],
    "textAnswer": "Giai thich y tuong",
    "fileUrl": null,
    "linkUrl": "https://github.com/user/repo"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "EXERCISE_SUBMISSION_CREATED",
  "message": "Exercise submitted.",
  "data": {
    "submissionId": "uuid",
    "exerciseId": "uuid",
    "status": "UNDER_REVIEW",
    "attemptNo": 1,
    "submittedAt": "2026-07-05T10:00:00Z"
  },
  "meta": {},
  "traceId": "uuid"
}
```

### PATCH `/api/v1/admin/exercise-submissions/{submissionId}/review`

Request:

```json
{
  "path": {
    "submissionId": "uuid"
  },
  "body": {
    "result": "NEEDS_REVISION",
    "score": 65,
    "feedback": "Can bo sung test case va giai thich thuat toan.",
    "allowResubmitUntil": "2026-07-12T10:00:00Z"
  }
}
```

Response:

```json
{
  "success": true,
  "businessCode": "EXERCISE_SUBMISSION_REVIEWED",
  "message": "Submission reviewed.",
  "data": {
    "submissionId": "uuid",
    "status": "NEEDS_REVISION",
    "score": 65,
    "resubmitAllowed": true
  },
  "meta": {},
  "traceId": "uuid"
}
```

## Ghi chu

- `DRAFT` khong tinh hoan thanh.
- Chi `PASSED` moi thoa bai tap bat buoc.
- Review cua Admin/Mentor can quyen phu hop.
