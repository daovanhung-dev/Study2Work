# AC - Admin Quan Ly Hoc Vien va Ho Tro Ngoai Le

## Bieu do

```mermaid
flowchart TD
    Start([Start])
    Search["Tra cuu hoc vien theo ten/email/phone/ma/lo trinh/trang thai"]
    Found{"Tim thay?"}
    Empty["Hien thi khong co ket qua"]
    Profile["Mo ho so ho tro hoc vien"]
    ViewProgress["Xem tai khoan, onboarding, lo trinh, tien do, bai tap, lich su"]
    Action{"Chon thao tac?"}
    Note["Ghi chu ho tro noi bo"]
    PathRequest["Xu ly yeu cau doi/reset/huy lo trinh"]
    RiskWarn["Hien thi canh bao tac dong"]
    Decision{"Chap thuan?"}
    Reject["Tu choi, ghi ly do"]
    Apply["Reset tien do / huy lo trinh active / chuyen lo trinh"]
    AccountAction["Khoa / mo tai khoan"]
    Reason["Nhap ly do bat buoc"]
    Audit["Ghi audit log va trang thai truoc/sau"]
    Notify["Thong bao ket qua cho hoc vien"]
    End([End])

    Start --> Search --> Found
    Found -->|Khong| Empty --> End
    Found -->|Co| Profile --> ViewProgress --> Action
    Action -->|Ghi chu| Note --> End
    Action -->|Ngoai le lo trinh| PathRequest --> RiskWarn --> Decision
    Decision -->|Khong| Reject --> Audit
    Decision -->|Co| Apply --> Audit
    Action -->|Khoa/mo tai khoan| AccountAction --> Reason --> Audit
    Audit --> Notify --> End
```

## Chuc nang bao phu

- Tra cuu hoc vien.
- Ho so ho tro hoc vien.
- Xem tien do hoc vien.
- Xu ly yeu cau doi lo trinh.
- Reset tien do.
- Huy lo trinh active.
- Khoa/mo tai khoan.
- Ghi chu ho tro.

## Quy tac

- Admin khong xem mat khau/OTP.
- Tien do khong duoc sua truc tiep ngoai quy trinh ngoai le.
- Doi/reset/huy lo trinh va khoa/mo tai khoan phai co ly do va audit log.
- Thao tac chuyen lo trinh khong duoc tao hai lo trinh `ACTIVE`.
