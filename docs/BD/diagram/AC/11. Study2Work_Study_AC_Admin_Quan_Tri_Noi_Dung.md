# AC - Admin Quan Tri Noi Dung

## Bieu do

```mermaid
flowchart TD
    Start([Start])
    SelectType{"Admin chon doi tuong?"}
    Path["Quan ly lo trinh"]
    Course["Quan ly khoa hoc"]
    Chapter["Quan ly chuong"]
    Lesson["Quan ly bai hoc"]
    Material["Quan ly tai lieu/tai nguyen"]
    Exercise["Quan ly bai tap/rubric"]
    Edit["Tao/sua noi dung, cau hinh bat buoc, mo khoa, hoan thanh"]
    Sort["Sap xep thu tu lo trinh/khoa/chuong/bai"]
    PrePublish["Kiem tra truoc xuat ban"]
    Checklist{"Dat checklist?"}
    Fix["Sua loi: thieu ten, muc tieu, dieu kien, source/quyen, link/video"]
    Impact{"Noi dung da xuat ban hoac anh huong hoc vien?"}
    Warn["Canh bao tac dong, phan loai sua nho/thay doi quan trong"]
    Publish["Xuat ban / cap nhat / luu tru"]
    Notify["Thong bao hoc vien bi anh huong neu can"]
    Audit["Ghi audit log cho publish/archive/dieu kien hoan thanh"]
    End([End])

    Start --> SelectType
    SelectType --> Path
    SelectType --> Course
    SelectType --> Chapter
    SelectType --> Lesson
    SelectType --> Material
    SelectType --> Exercise
    Path --> Edit
    Course --> Edit
    Chapter --> Edit
    Lesson --> Edit
    Material --> Edit
    Exercise --> Edit
    Edit --> Sort --> PrePublish --> Checklist
    Checklist -->|Khong| Fix --> Edit
    Checklist -->|Co| Impact
    Impact -->|Co| Warn --> Publish
    Impact -->|Khong| Publish
    Publish --> Notify --> Audit --> End
```

## Chuc nang bao phu

- Quan ly lo trinh, khoa hoc, chuong, bai hoc, tai lieu, bai tap.
- Sap xep noi dung.
- Kiem tra truoc xuat ban.
- Cap nhat noi dung da xuat ban.

## Quy tac

- Noi dung chua `PUBLISHED` khong hien thi cho hoc vien.
- Noi dung bat buoc phai co dieu kien hoan thanh ro rang.
- Bai hoc mau phai cau hinh rieng, khong mac dinh cong khai.
- Thay doi noi dung da xuat ban phai canh bao tac dong.
