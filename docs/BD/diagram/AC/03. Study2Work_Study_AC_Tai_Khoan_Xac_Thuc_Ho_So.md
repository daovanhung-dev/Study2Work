# AC - Tai Khoan, Xac Thuc va Ho So Hoc Vien

## Bieu do

```mermaid
flowchart TD
    Start([Start])
    Entry{"Nguoi dung chon chuc nang nao?"}
    Register["Dang ky: ten, email/phone, mat khau, dong y dieu khoan"]
    CreatePending["Tao tai khoan REGISTERED_PENDING_VERIFICATION"]
    SendVerify["Gui OTP/link xac thuc"]
    Verify["Xac thuc email/phone"]
    VerifyOk{"Xac thuc hop le?"}
    MarkVerified["Chuyen trang thai VERIFIED"]
    Login["Dang nhap bang email/phone + mat khau"]
    CheckStatus{"Trang thai tai khoan?"}
    Suspended["Thong bao bi tam ngung, chan hoc/noi dung rieng/link Zalo"]
    NeedVerify["Dieu huong man xac thuc"]
    NeedOnboarding["Dieu huong onboarding"]
    Ready["Dieu huong dashboard hoac kich hoat lo trinh"]
    Forgot["Quen mat khau: gui link/ma dat lai"]
    Reset["Dat mat khau moi va yeu cau dang nhap lai"]
    ChangePassword["Doi mat khau khi da dang nhap"]
    Profile["Xem/cap nhat ho so co ban, hoc tap, cai dat thong bao"]
    Reverify{"Doi email/phone?"}
    End([End])

    Start --> Entry
    Entry -->|Dang ky| Register --> CreatePending --> SendVerify --> Verify
    Verify --> VerifyOk
    VerifyOk -->|Khong| SendVerify
    VerifyOk -->|Co| MarkVerified --> NeedOnboarding
    Entry -->|Dang nhap| Login --> CheckStatus
    CheckStatus -->|SUSPENDED| Suspended --> End
    CheckStatus -->|Chua xac thuc| NeedVerify --> Verify
    CheckStatus -->|Chua onboarding| NeedOnboarding --> End
    CheckStatus -->|San sang hoc| Ready --> End
    Entry -->|Quen mat khau| Forgot --> Reset --> End
    Entry -->|Doi mat khau| ChangePassword --> End
    Entry -->|Ho so| Profile --> Reverify
    Reverify -->|Co| SendVerify
    Reverify -->|Khong| End
```

## Chuc nang bao phu

- Dang ky tai khoan.
- Xac thuc tai khoan.
- Dang nhap / dang xuat.
- Quen va doi mat khau.
- Ho so hoc vien.
- Quan ly trang thai tai khoan.

## Quy tac

- Tai khoan chua xac thuc khong kich hoat lo trinh va khong luu tien do chinh thuc.
- Thay doi email/phone can xac thuc lai kenh moi.
- Admin khong nhin thay mat khau, OTP hoac link xac thuc.
- Hoc vien khong sua truc tiep tien do/diem/trang thai hoan thanh.
