# Study2Work - Study
## Basic Design: Admin Bao Cao va Chi So Van Hanh

> **STT:** 12  
> **Nguon:** `0. Study2Work_Study_Business_Description.md`  
> **Pham vi:** Mo ta chuc nang bao cao va dashboard van hanh cho Admin. Khong mo ta kho du lieu, truy van, API, pipeline phan tich hoac cong cu BI ky thuat.

---

## 1. Muc tieu module

Module Bao cao va Chi so van hanh giup Admin hieu he thong Study dang hoat dong ra sao, nguoi hoc co bi nghen o dau va noi dung nao can cai thien.

Muc tieu:

- Theo doi tang truong tai khoan va chuyen doi den hoc tap.
- Theo doi ti le hoan thanh onboarding, lo trinh, khoa hoc, chuong.
- Phat hien bai hoc/bai tap co ty le bo do hoac chua dat cao.
- Theo doi nhu cau cong dong thong qua luot mo link Zalo.
- Ho tro quyet dinh cai tien noi dung va quy trinh onboarding.

---

## 2. Doi tuong su dung

| Vai tro | Chuc nang lien quan |
|---|---|
| Admin | Xem dashboard van hanh tong quan. |
| Content Admin | Xem chi so noi dung, bai hoc, bai tap. |
| Learner Support | Xem chi so onboarding, yeu cau ho tro va doi lo trinh. |
| Super Admin | Xem chi so tong quan va xu huong. |

---

## 3. Dashboard van hanh tong quan

Dashboard tong quan can hien thi:

- So tai khoan moi.
- Ty le xac thuc tai khoan.
- Ty le hoan thanh onboarding.
- So hoc vien kich hoat lo trinh.
- Ty le bat dau khoa hoc dau tien.
- Ty le hoan thanh lo trinh.
- Bai hoc co ty le bo do cao.
- Bai tap co ty le chua dat cao.
- So yeu cau doi/reset lo trinh.
- So luot mo lien ket Zalo.

Bo loc chung:

- Khoang thoi gian.
- Lo trinh.
- Khoa hoc.
- Cap do.
- Nhom hoc vien neu co.
- Trang thai tai khoan/lo trinh.

---

## 4. Chi so can theo doi

| Chi so | Y nghia |
|---|---|
| So tai khoan moi | Do muc do thu hut nguoi dung. |
| Ty le xac thuc tai khoan | Phat hien diem nghen sau dang ky. |
| Ty le hoan thanh onboarding | Do muc do de hieu cua quy trinh ban dau. |
| So hoc vien kich hoat lo trinh | Do muc chuyen doi tu onboarding sang hoc. |
| Ty le bat dau khoa hoc dau tien | Phat hien nguoi dung dang ky nhung khong hoc. |
| Ty le hoan thanh chuong/khoa hoc/lo trinh | Do hieu qua noi dung va do phu hop do kho. |
| Bai hoc co ty le bo do cao | Canh bao noi dung qua kho, qua dai hoac loi. |
| Bai tap co ty le chua dat cao | Goi y can them vi du, hint hoac sua yeu cau. |
| So yeu cau doi lo trinh | Do chat luong goi y onboarding va tinh phu hop lo trinh. |
| So luot mo lien ket Zalo | Do nhu cau cong dong; khong dong nghia so nguoi da tham gia nhom. |

## 5. Chuc nang chi tiet

### 5.1. Bao cao dang ky va xac thuc

Can hien thi:

- So dang ky moi theo ngay/tuan/thang.
- Ty le xac thuc thanh cong.
- So tai khoan chua xac thuc.
- Thoi gian trung binh tu dang ky den xac thuc.
- Ty le roi bo truoc xac thuc.

Y nghia:

- Phat hien loi hoac diem kho trong buoc xac thuc.
- Danh gia hieu qua thong diep dang ky.

### 5.2. Bao cao onboarding

Can hien thi:

- Ty le bat dau onboarding.
- Ty le hoan thanh onboarding.
- Buoc onboarding co ty le roi bo cao.
- Muc tieu hoc pho bien.
- Muc do nen tang pho bien.
- Ty le hoc vien chon lo trinh theo goi y.

Y nghia:

- Cai thien cau hoi onboarding.
- Dieu chinh goi y lo trinh.
- Phat hien buoc qua dai hoac kho hieu.

### 5.3. Bao cao lo trinh

Can hien thi theo tung lo trinh:

- So hoc vien kich hoat.
- So hoc vien dang hoc.
- So hoc vien da hoan thanh.
- Ty le hoan thanh.
- Thoi gian trung binh de hoan thanh.
- Khoa hoc co ty le roi bo cao trong lo trinh.
- So yeu cau doi/reset lien quan.

Y nghia:

- Danh gia do phu hop cua lo trinh.
- Phat hien lo trinh qua dai, qua kho hoac sai doi tuong.

### 5.4. Bao cao khoa hoc va bai hoc

Can hien thi:

- Ty le bat dau khoa hoc.
- Ty le hoan thanh khoa hoc.
- Bai hoc co ty le dung lai cao.
- Bai hoc co nhieu bao loi.
- Thoi luong hoc trung binh neu co so lieu.
- Noi dung duoc xem lai nhieu.

Y nghia:

- Cai thien video, tai lieu, vi du.
- Rut ngan hoac chia nho bai hoc qua dai.

### 5.5. Bao cao bai tap

Can hien thi:

- So lan nop bai.
- Ty le dat/chua dat/can sua.
- Bai tap co ty le chua dat cao.
- Thoi gian trung binh tu mo bai den nop bai.
- So bai dang cho review.

Y nghia:

- Phat hien bai tap qua kho hoac yeu cau khong ro.
- Dieu phoi nguoi cham bai neu review bi ton dong.

### 5.6. Bao cao cong dong

Can hien thi:

- So luot mo link Zalo theo lo trinh/khoa hoc.
- Nhom co nhieu luot mo.
- Nhom co bao cao link hong/spam.
- Nhom da tam dung hoac can cap nhat.

Luu y: So luot mo link khong dong nghia so hoc vien da tham gia nhom.

### 5.7. Canh bao van hanh

He thong nen co canh bao cho:

- Ty le xac thuc giam bat thuong.
- Buoc onboarding co ty le roi bo cao.
- Khoa hoc co ty le bo do cao.
- Bai tap co ty le chua dat cao.
- So bai cho review vuot nguong.
- Link Zalo bi bao loi nhieu lan.

Canh bao la thong tin ho tro ra quyet dinh, khong tu dong thay doi noi dung.

## 7. Tieu chi hoan tat module

- Admin xem duoc dashboard tong quan ve tai khoan, onboarding, hoc tap, bai tap va cong dong.
- Co bo loc theo thoi gian, lo trinh va khoa hoc.
- Content Admin xem duoc diem nghen noi dung.
- Learner Support xem duoc chi so lien quan onboarding va yeu cau ho tro.
- Bao cao khong lam lo du lieu ca nhan khong can thiet.
