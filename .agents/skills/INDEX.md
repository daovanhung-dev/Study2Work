# Skill registry

Skills are loaded by task trigger and scope. They are not runtime source and do
not become active merely because a file exists.

| Skill | Entry | Trigger | Scope |
|---|---|---|---|
| `createDD-markdown` | `create_dd/docs/dd/createDD_MARKDOWN_SKILL.md` | API DD authoring, conversion or review | Study, Work, AI and cross-scope Web/API work |

Resources for this skill are the baseline template and the two source-preserving
examples registered in `context-manifest.json`.
