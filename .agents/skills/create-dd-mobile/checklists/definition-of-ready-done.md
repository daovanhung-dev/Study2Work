# Definition of Ready / Done

## Definition of Ready

Module ready for coding khi BD/requirement có nguồn rõ, Overall đã chốt scope,
roles, rules, flow, dependencies; feature chính, views, acceptance criteria và
open-question ownership đã được xác định.

## Definition of Done

DD done khi đủ required files, IDs ổn định, traceability liên tục, error/permission/
validation flow được mô tả, Import/File map đủ cho coding, changelog/review status
có mặt, validator PASS và BA/PO, Tech Lead, QA đã review phần trách nhiệm của họ.

`Approved` không thay thế implementation, runtime hoặc sandbox acceptance.
