# Work API

NestJS + Fastify foundation for the Work subsystem.

## Commands

```powershell
pnpm install
pnpm --filter work-api lint
pnpm --filter work-api typecheck
pnpm --filter work-api test
pnpm --filter work-api build
pnpm --filter work-api dev
```
