1. Mục tiêu & Yêu cầu cốt lõi

Học viên chịu trách nhiệm triển khai giao diện điều hành phân tích dữ liệu chuyên nghiệp (Enterprise Data Dashboard), xử lý mượt mà trên 10,000+ records dữ liệu thực tế từ RESTful endpoint.

▤ Virtualization & Rendering

Áp dụng TanStack Virtual hoặc React Window để duy trì 60 FPS khi cuộn danh sách dữ liệu hàng nghìn dòng.

⌕ Server-side Filtering & Debounce

Cơ chế đồng bộ URL SearchParams, xử lý debounce input và cập nhật bảng bất đồng bộ không gây giật lag UI.

♙ Phân quyền RBAC động

Mô phỏng 3 vai trò: Admin, Finance Analyst, Viewer với giới hạn quyền xuất báo cáo.

◐ Chế độ hiển thị đa giao diện

Tối ưu Dark/Light Mode với CSS Custom Properties và lưu trữ state trên LocalStorage.
