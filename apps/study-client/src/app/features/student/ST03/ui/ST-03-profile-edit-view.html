Technical Gate G-03

Tài liệu chẩn đoán dành cho Backend Core & Database Admin về các blocker trên Route /student/profile/edit:

1. API #13 POST /users/me/avatar Asset Mismatch

API #13 nhận JSON chứa image Data URL và trả avatar_url sau khi ghi object storage. Cần thống nhất tham chiếu avatar, quyền truy cập ảnh và luồng lưu qua API #14 trước khi mở upload.

2. API #14 PUT /users/me/profile DDL Missing Fields

Trường bio không có trong DDL hiện tại. Cột phone có trạng thái nullable nhưng thiếu validation regex và quy tắc lưu đồng bộ.

✓ Bước tiếp theo: Chờ xác nhận hợp đồng API #13 và #14 trước khi mở chức năng chỉnh sửa hồ sơ.
