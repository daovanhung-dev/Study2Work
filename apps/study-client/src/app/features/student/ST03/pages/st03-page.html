Technical Gate G-03

Các điểm cần chốt trước khi mở Route /student/profile/edit:

1. API #13 POST /users/me/avatar

Server nhận JSON Data URL và lưu object storage. Client chưa có policy encode/preview, thay thế ảnh và xử lý lỗi upload.

2. API #14 PUT /users/me/profile

Body hiện chỉ cập nhật full_name, phone và avatar_url; bio không được lưu. Quy tắc phone/avatar chưa thống nhất với yêu cầu màn hình.
