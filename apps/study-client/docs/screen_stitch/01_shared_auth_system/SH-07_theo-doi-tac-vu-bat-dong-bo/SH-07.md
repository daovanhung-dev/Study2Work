## 2. Nguồn, current behavior và expected behavior

### Expected behavior

- SH-07 theo inventory dùng để xem job thanh toán/gửi thông báo/xuất báo cáo; chỉ dùng operation ID do backend xác nhận; lấy status qua API #18 nếu ID và contract đã thống nhất; dừng theo terminal state đã định nghĩa.
- API #18 catalog row: Bearer JWT; operation owner; path `operation_id:int64`; response `ApiEnvelope<Operation>`; success HTTP 200 `DESIGN_OPERATION_RETRIEVED`; lỗi 401 `DESIGN_AUTHENTICATION_REQUIRED`, 403 `DESIGN_ACCESS_DENIED`, 404 `DESIGN_RESOURCE_NOT_FOUND`, 500 `DESIGN_INTERNAL_ERROR`.
- Reusable `Operation` schema: `id:uuid`, `kind:OperationKind`, `status:OperationStatus`, `owner_id:int64`, `submitted_at`, `updated_at`, optional `completed_at`, optional `result:Payment`. Giá trị của `OperationKind`/`OperationStatus`, result theo từng kind, lifecycle và mapping chủ sở hữu chưa được định nghĩa.

### Current behavior

- `screen.png` là một trạng thái gate tĩnh `Gated / Unavailable`; nhãn môi trường `STAGING-MOCK-07`; không hiển thị response API thật. `code.html` không có fetch/poll/SSE.
- Script prototype đọc segment sau `/operations/`; nếu thiếu thì gán UUID minh họa `9a7f34e2-76b1-4c33-bf92-1dc3f8489e24`. Đây là fallback mock, không phải nguồn ID.
- Lifecycle cards `QUEUED`, `RUNNING`, `SUCCEEDED`, `FAILED`, `EXPIRED` là text tĩnh. Chúng không bind vào một Operation object.
- “Xem Contract Spec” chỉ bật/tắt modal DOM; copy button copy text ID hiện có. Modal có ví dụ schema/status/result và đề xuất polling 3000ms/backoff hoặc SSE, nhưng không gọi API.

## 4. Luồng hoạt động tổng thể

### 4.1. Trạng thái prototype hiện có

1. Browser render HTML prototype, không có router hay API client được xác minh.
2. Inline script đọc `window.location.pathname`; nếu match `/operations/<segment>` thì thay text ID bằng segment đó. Nếu không match, script gán UUID mẫu. Không có validation/auth/owner check.
3. UI hiển thị gate banner, mock environment, ID mẫu hoặc path text, các lifecycle reference cards và developer diagnostic. Không có status fetch, polling, timer, SSE, result download, cache hoặc error mapping.
4. Click “Xem Contract Spec” bật modal; click hai close controls đóng modal. Copy button gọi Clipboard API với text đang hiển thị. Các anchor route đều `href="#"`.

### 4.2. Luồng mục tiêu chỉ sau khi contract được duyệt

1. Caller (ST-06/ME-14/AD-20/AD-25 theo contract tương ứng) nhận một ID từ backend. Client chỉ điều hướng tới SH-07 sau khi ID field/path và producer response được thống nhất; không tự tạo ID và không suy từ notification ID sang operation ID.
2. Router xác thực format theo kiểu ID đã được contract owner chốt. Hiện không có quyết định giữa UUID và int64; do đó chưa thể viết validator/canonicalizer.
3. Backend phải thực thi Bearer authentication, role/ownership policy và lookup operation. SH-07 không tự xác thực quyền bằng `owner_id` trên client.
4. Khi API #18 route/module/response được triển khai và contract đã chốt, client gửi một GET ban đầu. Không gửi query/body; không gọi API #18 hiện tại vì route chưa tồn tại.
5. Client kiểm tra HTTP status, business code, envelope, field types và Operation status/kind theo canonical schema. Hiện các enum/result/ownership field mapping còn SOURCE_REQUIRED.
6. Chỉ khi mapping status được phê duyệt mới render status thật, timestamp và hành động được phép. Không dựng %, countdown, kết quả thanh toán, sent count hoặc download URL nếu API không trả field được contract định nghĩa.
7. Polling/SSE, cache, retry/backoff, interval, visibility/reconnect và điểm dừng phải được quyết định trước. HTML gợi ý hai cách nhưng không tạo contract.
8. Sau terminal state, cập nhật màn hình theo chính payload backend và điều hướng theo caller context đã được duyệt. Hiện `terminal states` và safe-return target chưa được thống nhất.

- **Trigger/element:** browser navigation tới route đề xuất `/operations/:operationId`; không có marker riêng ngoài breadcrumb/ID element #8/#12.
- **Loại:** route load / page initialization.

- **Current processing:** inline script tìm `/operations/([^/?#]+)` rồi hiển thị capture; nếu thiếu match thì đặt UUID mẫu. Không xác thực ID, role hoặc owner; không có API call.
- **Target ordering:** (1) lấy path segment; (2) chưa canonicalize/regex validate cho tới khi chủ contract chốt UUID/int64; (3) xác nhận caller đã nhận đúng field từ producer, không map notification ID; (4) nếu endpoint chưa sẵn sàng, render `DESIGN_GATE`/unavailable state đã được product duyệt và không request/poll; (5) không đưa fake fallback vào UI; (6) nếu route param thiếu/hỏng, route fallback policy còn cần xác nhận.

### `SH07-EV-05` — Đọc operation status lần đầu (chưa runnable)

- **Trigger/element:** route initialization sau khi API #18/ID/authorization/producer contract được duyệt. Event này là expected design, không phải current HTML behavior.
- **Input:** `operation_id` từ path; Bearer JWT từ auth layer. Không có query parameter/body.

- **Processing:** (1) lấy path ID đã được upstream phát; (2) không convert kiểu trước khi API contract chốt; (3) backend thực thi auth/authorization; (4) gửi một GET khi endpoint có route; (5) validate envelope/business code/trace ID và field types; (6) map `kind/status/result` chỉ sau khi schema/enum/by-kind result được duyệt; (7) không lưu/cập nhật cache nếu chưa có freshness policy; (8) hiển thị đúng status hoặc branch theo policy.
- **Current behavior:** API #18 không có route/module/query/test; không gửi request. Contract is `D`/Draft, nên call không runnable.
- **Success/error handling:** 200 mapping chưa hoàn tất vì enums/result fields unresolved; 401/403/404 expected design codes, nhưng wrong-owner 403 vs 404 unresolved; 500/network/timeout stay service error and must not become 404. Retry/timeout policy not specified; do not invent.

## 9. Bảo mật, accessibility và design system

- Hiển thị operation chỉ sau khi server áp dụng authorization. Không tin `owner_id` từ client state và không đoán quyền Admin. 403/404 semantics phải được chốt để hạn chế IDOR/resource-existence leakage.
- Operation ID phải từ producer đã được contract phê duyệt; không dùng fallback mẫu hoặc ID lấy từ notification path. Không log response/result URL/raw error vào console.
- Không hiển thị raw database/internal details. `Developer Hand-off & Schema Diagnostic`, `STAGING-MOCK-07`, “migration v2.4” và `HANDOFF_STRICT` là mock/dev content; cần loại khỏi user production surface hoặc duyệt audience/feature gate riêng.
- Chỉ render result/download affordance nếu per-kind API schema cho biết trường và ownership/expiry policy; hiện `result_url` chưa thuộc generic Operation schema.
- Header account icon hiện là `div` không tương tác; không tạo profile button nếu chưa có requirement. Anchor `href="#"` không phải route hoạt động. Cần semantics/focus-visible cho controls.
- Modal phải dùng semantic dialog, quản lý focus vào/ra, keyboard close theo quyết định; hidden modal không có marker trong ảnh mặc định nhưng cần được kiểm tra khi implement.
- State labels có text kèm màu/chấm; giữ tên state bằng text và announce updates với screen reader chỉ khi có status source thật. Không chỉ dùng màu hoặc animation pulse.
- Design guide target: Inter nếu đã có hoặc system font, không tải remote font; content width khoảng 1120px; reflow ở mobile/tablet/desktop và không ẩn primary navigation/actions; controls ≥44px. Prototype dùng Plus Jakarta Sans/Material Symbols remote, Tailwind CDN, 1440px max width, nav ẩn dưới `md`, icon account 32px. Đây là design drift cần xử lý ở implementation.
- SVG architecture diagram hiện không có accessible label/hidden semantics. Status screenshot có `animate-pulse`; theo guide phải tôn trọng `prefers-reduced-motion` khi dùng animation trong runtime.
