Lifecycle Hợp đồng Thiết kế

Đặc tả chuẩn các pha vận hành của một Background Task
account_tree
queued
Hàng đợi

Task đã được xác thực và tiếp nhận vào Message Broker (RabbitMQ / Redis Queue). Chưa có Worker thread nhận lệnh xử lý.

running
Đang chạy

Worker node đã cấp phát tài nguyên tính toán. Thao tác I/O đang diễn ra (gọi thanh toán cổng thứ 3, tổng hợp dữ liệu PDF).

succeeded
Hoàn thành

Tác vụ hoàn tất thành công. Trả về payload kết quả chính thức hoặc URL đích kèm chữ ký bảo mật xác thực (S3 Presigned URL).

failed
Thất bại

Xảy ra ngoại lệ nghiêm trọng (Exception, Gateway Timeout, Lỗi thanh toán từ bên thứ 3). Đi kèm mã error_code chi tiết.

expired
Hết hạn

Vượt quá thời gian TTL lưu vết (mặc định 24h đối với tác vụ tải xuống, 15 phút đối với phiên cổng thanh toán chưa kết thúc).
