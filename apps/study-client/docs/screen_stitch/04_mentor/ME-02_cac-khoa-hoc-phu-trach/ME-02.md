## 2. Luồng tổng thể

1. Người dùng đi tới route đề xuất `/mentor/courses`. Route, token/session hydration và role-aware shell chưa tồn tại trong Study Web source hiện tại.
2. Khi client được triển khai, chỉ gửi Bearer access token theo auth boundary của app; không nhận `mentor_id` từ query hoặc form. Current #46 guard đọc và xác thực JWT claims, yêu cầu role `MENTOR`, rồi lấy numeric `sub` làm principal.
3. Gọi `GET /api/v1/mentor/courses` với query đã được quyết định. Không gửi search/level/sort/semester/status label của mockup khi chưa có mapping. Query defaults current: `page=1`, `size=20`, không có status filter.
4. #46 validate `status` thuộc `DRAFT|PUBLISHED`, page `>=1`, size `1..100` trước DB query. Nếu hợp lệ, count và page query cùng áp dụng owner/status predicate; SQL order cố định `courses.created_at DESC, courses.id ASC`; query chỉ đọc.
5. View kiểm tra count/projection, map từng row thành `Course`, tính `total_pages`, rồi trả success envelope `DESIGN_RESOURCE_RETRIEVED`. `items=[]` là 200 thành công; out-of-range page cũng có thể trả `items=[]` nhưng vẫn giữ `total`/`total_pages`.
6. Chỉ các field có trong Course response được coi là current source data. Không suy ra KPI, status label, course code, rating, module/lab count hay capability/assignment từ nội dung mẫu.
7. Chọn một card có thể điều hướng sang ME-03 với `Course.id` nếu route/ownership handoff được duyệt. Các action khác hiện là target đề xuất hoặc blocker trong §5 và §7.

### Source trace — API #46

```text
GET /api/v1/mentor/courses
  -> apps/study-server/app/api/v1.py:mentor_courses
  -> MentorCourseQuery(status, page, size)
  -> app.modules.mentor.api_46_mentor_courses.view.get_mentor_courses
  -> validate_current_user_request(role="MENTOR")
  -> validate status DRAFT|PUBLISHED, page>=1, size 1..100
  -> count_owned_courses / find_owned_courses
       -> COUNT + LIST SQL; courses.mentor_id = JWT sub; optional exact status
       -> LEFT JOIN users; ORDER BY created_at DESC, id ASC; LIMIT/OFFSET
  -> map_course -> CoursePage(items, pagination)
  -> ApiEnvelope success DESIGN_RESOURCE_RETRIEVED or safe error response
  -> test source covers auth/query/page/empty/error branches (read, not run)
```

`find_owned_courses` và `count_owned_courses` dùng cùng direct-owner predicate và status nếu có. GET không ghi dữ liệu, không commit và không có external side effect. Query/status validation diễn ra sau auth guard; sai role trả 403 trước query. Test source dùng fake DB session/rows, vì vậy không xác minh live schema, deployment hay PostgreSQL query execution. DB context ghi live schema là `NOT_VERIFIED`.

## 4. Event specifications

### `ME02-EV-01` — Vào màn hình và tải danh sách

- **Trigger / type:** Route enter / page load.
- **Input:** Route `/mentor/courses`; active Mentor access token do app shell quản lý; optional `status`, `page`, `size` chỉ khi UI state được thống nhất.
- **Precondition:** Mentor session hợp lệ. Current Study Web route/session `UNWIRED`.
- **API:** `GET /api/v1/mentor/courses`, `Authorization: Bearer <JWT>`, no body; default page=1,size=20, omit status.
- **Steps:** (1) Router/auth shell phải kiểm role trước khi render; (2) gọi #46; (3) API guard xác thực JWT/`MENTOR` trước DB; (4) validate query; (5) count và page cùng owner/status predicates; (6) map CoursePage; (7) khi success, bind Course fields/pagination theo §6; (8) không render sample KPI như runtime data.
- **Output:** 200 `DESIGN_RESOURCE_RETRIEVED`; `data.items` rỗng vẫn là success. Có thể giữ `partial` widget state chỉ khi sau này nhiều API được phê duyệt; hiện inventory ME-02 chỉ có #46.
- **Errors:** 401 authentication, 403 role denial, 422 query validation, 500 safe internal error; network/timeout/cache/retry presentation chưa được thiết kế.

### `ME02-EV-02` — Tìm tên/mã khóa học

- **Trigger / type:** Input/change trên #15.
- **Input:** String tên hoặc mã course; mockup có example `FE-ENT-04`.
- **Precondition:** Search contract và endpoint được duyệt.
- **Steps/output:** #46 hiện không có `q` hay course-code query; không gửi tham số không khai báo và không lọc giả ở client trên một page. Debounce, normalization, empty-query behavior, page reset và cross-page search đều `BLOCKED` tới khi có contract/source hỗ trợ.

### `ME02-EV-03` — Lọc status

- **Trigger / type:** Change #16 hoặc remove status chip #19.
- **Input:** UI values `all|active|upcoming|archived`.
- **Precondition:** Product/BE chốt mapping sang enum server.
- **Steps:** `all` tương ứng omit status theo API; current source chỉ nhận exact `DRAFT|PUBLISHED`. Không tự map các label khác. Sau khi mapping được duyệt, gửi status, page và size hợp lệ; count/list của #46 cùng filter.

## 5. API contract và response mapping

### API #46 — `GET /api/v1/mentor/courses`

| Thuộc tính | Current source |
|---|---|
| Authentication | Header `Authorization: Bearer <JWT>`; shared `validate_current_user_request(..., role="MENTOR")`. Missing/invalid token → 401; valid token without MENTOR role → 403, trước DB query. JWT `sub` hiện được parse thành numeric user ID dương. |
| Query | `status?: string` enum source `DRAFT|PUBLISHED`; `page?: int` default 1/min 1; `size?: int` default 20/min 1/max 100. No request body. |
| Query effect | `status` absent → no status predicate; provided → exact equality. Both count/page predicate direct `courses.mentor_id = :mentor_id`. Fixed order `created_at DESC, id ASC`; limit/offset from page/size. GET read-only. |
| Success | HTTP 200, `businessCode=DESIGN_RESOURCE_RETRIEVED`, envelope `success/businessCode/message/data/meta/traceId`. Empty page message “No courses found.”; data still `items:[]` plus pagination. |
| `data.items[]` | `id:int`, `title:string`, `description?:string|null`, `thumbnail_url?:string|null`, `price:decimal string`, `status:string` (current output constrained to DRAFT/PUBLISHED), `mentor:{id:int, full_name:string, avatar_url?:string|null}`. No `course_code`, level/category, rating, count or progress fields. |
| `data.pagination` | `page`, `size`, `total`, `total_pages`; `total_pages=0` if total=0. Out-of-range page may have `items=[]` while `total` remains positive. |
| Errors | 401 `DESIGN_AUTHENTICATION_REQUIRED`; 403 `DESIGN_ACCESS_DENIED`; 422 `DESIGN_VALIDATION_ERROR` for status/page/size; 500 `DESIGN_INTERNAL_ERROR` for DB/integrity/mapping failures. Trace ID is preserved by shared response helpers. |

#### Response-to-UI allowlist

| API field | UI use | Restriction |
|---|---|---|
| `id` | Route context for card actions, only after destination approval. | Do not display as course code without product definition. |
| `title` | Course heading. | Text sample replaced by current field after success. |
| `description` | Supporting text. | Nullable; fallback/truncation rules need UI design. |
| `thumbnail_url` | Course image. | Nullable URL; loading/failed-image state not designed. HTML remote image URLs are sample assets. |
| `status` | Raw status text or approved translation. | Do not map to active/upcoming/archived without approved mapping. |
| `price` | Not visibly required by screenshot. | Preserve decimal string if later displayed; no currency symbol/currency field supplied. |
| `mentor` | Not needed within each owned course card. | Does not provide Mentor job title, availability or profile record. |
| `pagination.*` | Result count/page controls/page-size state. | Count reflects current direct-owner/status query; it does not mean “eligible/assigned/active” until scope is resolved. |

## 8. Security, accessibility and design notes

- Never infer ownership in the browser; backend auth/scope remains authoritative. #46 gets principal from JWT; the UI cannot select `mentor_id`.
- `courses.mentor_id` direct-owner logic does not satisfy AC-21 “owns/assigned” if assignment is a separate concept; keep assigned courses unavailable until source/API supports them.
- Preserve 401/403 distinctions in API calls; no client retry policy, refresh flow, redirect or token storage is source-backed here.
- Intended Study Web design guide uses Ocean primary `#0B5F8A`, Inter/system font, controls at least 44px, content width about 1120px and keyboard/focus/reflow expectations. Prototype uses primary `#004ac6`, remote Plus Jakarta Sans and Tailwind CDN, 32–40px controls and max-width 1440px. Resolve before implementation; do not treat prototype style as approved exception.
- The header/profile and support/footer content includes sample personal/contact/brand/certification claims. Keep accessible labels, links and externally displayed contact/credentials out of live UI until ownership and content are approved.
- Require semantic buttons/links, visible focus, accessible names for icon-only controls, form labels/errors, responsive reflow and reduced-motion handling according to the design guide. Current HTML controls lack many of these semantics/labels.
