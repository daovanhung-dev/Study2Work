### A.2. Điều kiện vào, dữ liệu và rời màn hình

- **Điều kiện truy cập server:** Bearer token hợp lệ, JWT subject là số và có role `MENTOR`. API #54 xác minh role trước truy vấn. Quyền client-side/session guard chưa có source.
- **Điều kiện dữ liệu:** `course_id` tùy chọn; nếu có thì phải là số nguyên dương trong miền signed int64. `status` tùy chọn là string khớp chính xác. `page` mặc định `1`, dương và không vượt signed int32. Kích thước trang hiện cố định `20`.
- **Kết quả đọc:** API #54 trả `data.items` và `data.pagination`; `items=[]` là kết quả thành công, không phải lỗi.
- **Rời màn hình:** Khi có row và lựa chọn hợp lệ, lấy `data.items[].id` làm giá trị path `submission_id` cho ME-10. Current response không có key `submission_id`; cách gọi tên ở inventory và tên field source là một điểm cần xác nhận khi khóa client model.
- **Không được xem là tiền điều kiện đã hoàn tất:** route/session guard, course options, state URL/cache, auto-refresh, deadline và rubric chưa có frontend hoặc API contract hoàn chỉnh.

### A.3. Expected behavior và current behavior

**Expected behavior:** Mentor truy cập danh sách bài nộp, lọc theo khóa học/trạng thái, xem các bài phù hợp và mở chi tiết một bài. Inventory muốn deadline/owner và route sang ME-10. Các trạng thái màn hình đề xuất trong inventory là `loading/empty/ready/error`.

**Current UI assets:** [ảnh gốc](screen.png) và [HTML](code.html) thể hiện duy nhất empty state. Không có table/card/hàng, không có trang loaded, không có biểu diễn deadline/owner, không có pagination hoặc lỗi. HTML có các lựa chọn khóa học/status tĩnh và ô search, không gửi request. Nút refresh chỉ animate/disable trong 750 ms; nút reset chỉ đặt lại giá trị cục bộ. Header, notification, profile và footer có `href="#"`.

**Current API source:** route/module/query/model của #54 hiện trả `ApiEnvelope<Page<Submission>>`, trong đó `Submission` có `id`, `assignment_id`, `user_id`, `content?`, `files[]`, `status`, `submitted_at`, `score?`, `feedback?`. API không trả due date, assignment title, course title, `course_id`, Student display name hay rubric. `user_id` không tương đương tên/nhãn “owner”.

### B.1. Luồng tải màn hình dự kiến

1. Người dùng vào route đề xuất `/mentor/submissions`. Study Web route chưa tồn tại; guard, token source và fallback phiên hết hạn chưa được triển khai.
2. Client cần gửi Bearer token cho #54. Server kiểm tra chữ ký/subject/role MENTOR trước mọi DB access. Client role label không thay thế authorization của server.

## D. Đặc tả sự kiện

### ME09-E01 — Vào màn hình / tải danh sách

- **Element:** route ME-09; trigger `Load`.
- **Tiền điều kiện:** user có session/token hợp lệ và MENTOR role; UI token/session source chưa có trong checkout.
- **Input:** optional `course_id:int64`, `status:string`, `page:int32`; API defaults `course_id=null`, `status=null`, `page=1`. Page size server 20.
- **Xử lý dự kiến:**
  1. Đọc route và auth state theo implementation contract sẽ được phê duyệt; không lấy profile mẫu từ HTML.
  2. Chỉ dựng query từ field #54 đã hỗ trợ; không gửi `q`, `size`, sort hoặc UI value chưa map.
  3. Gọi `GET /api/v1/mentor/submissions` với `Authorization: Bearer ...`.
  4. Nhận response, kiểm tra HTTP status, `success`, `businessCode` và shape `data.items/data.pagination` theo current source.
  5. `items=[]` → empty state; non-empty → loaded state cần row layout được duyệt; không suy deadline/owner/title.
  6. Lỗi → state tương ứng; API error phải giữ `traceId` cho hỗ trợ, không hiển thị raw SQL.
- **Output:** loading → empty/ready/error/auth/access/validation. Request lifecycle và UI mapping chưa chạy trong app.
- **Current source:** #54 GET source-backed, screen event UNWIRED.

### D.1. Error/business code mapping cho #54

| HTTP | Current API behavior | Xử lý màn hình yêu cầu sau khi UI contract được duyệt |
|---:|---|---|
| 200 | `DESIGN_RESOURCE_RETRIEVED`; có items hoặc Page rỗng. | Empty/ready theo `items.length`, không dựa vào message text. |
| 401 | Bearer/token/claims không hợp lệ hoặc thiếu. | Hiển thị yêu cầu đăng nhập/hết phiên theo auth policy; policy/route chưa được source-backed. |
| 403 | Role không phải MENTOR hoặc course filter trỏ tới owner khác. | Hiển thị quyền bị từ chối, không lặp lại request vô hạn. |
| 422 | `course_id`/`page` sai range hoặc request query invalid theo route constraints. | Map field/query error; status string hiện không có enum validation. |
| 409 | Có khai báo trong catalog/AC node cũ nhưng không có nhánh 409 trong current view. | Không tạo UI conflict behavior cho #54 đến khi có trigger/business rule. |
| 500 | SQL/projection failure → `DESIGN_INTERNAL_ERROR`. | Hiển thị lỗi an toàn và giữ trace ID; retry policy/chính sách giữ dữ liệu cũ cần quyết định. |
| Network/timeout | Không phải business code; chưa có client source. | Chưa xác định timeout, cancel, retry hoặc stale data behavior. |

## E. Trạng thái, bảo mật và khả năng truy cập

### E.1. Ma trận trạng thái

| State | Điều kiện chuyển vào | UI/behavior | Mức bằng chứng |
|---|---|---|---|
| `loading` | Route entry hoặc request #54 đang pending. | Không hiển thị empty copy như kết quả cuối trước response. | Required design; chưa có trong asset/source. |
| `empty` | HTTP 200, `data.items=[]` (bao gồm no match/missing course trong source). | Có thể dùng empty visual hiện tại sau khi sửa copy về direct-owner/no match và bỏ auto-sync claim chưa được chứng minh. | Asset hiện có; runtime mapping chưa wired. |
| `ready` | HTTP 200, `data.items.length>0`. | Cần row/card, field list, paging và row action được duyệt; không có mock loaded asset. | API source-backed; UI design gap. |
| `refreshing` | Người dùng bấm reload và #54 request đang chạy. | Prototype hiện chỉ animate cục bộ; chưa có network state. | UNWIRED. |
| `error` | Network error hoặc server 500. | Hiển thị lỗi; retry/keep-old-data policy cần chốt. | Current API error source; UI chưa wire. |
| `auth-required` | #54 trả 401. | Theo auth flow đã duyệt; screen không tự xử lý/refresh token theo giả định. | Server source-backed; client flow UNWIRED. |
| `access-denied` | #54 trả 403. | Báo không đủ quyền; không render sample data. | Server source-backed. |
| `filter-validation-error` | #54 trả 422 do numeric range/request constraints. | Gắn lỗi vào query/control hợp lệ; status unknown hiện có thể empty 200. | Server source-backed; UI chưa wire. |
| `navigating-detail` | User activate một row đã tải. | Dùng item `id` làm #55 path; tránh gửi nhầm assignment ID. | Handoff expected; row/route chưa tồn tại. |

### E.2. Bảo mật và data handling

- API #54 là boundary bảo mật: shared guard yêu cầu role `MENTOR` trước DB; mọi count/list query lọc theo direct `courses.mentor_id`. Không coi hidden UI hoặc role label từ HTML là authorization.
- Theo fallback hiện hành, assigned Mentor không có access relation. Không cho UI giả định assignment/course membership tương đương direct owner. Nếu #54 trả 403, không thử gọi #55 bằng cùng ID để vượt scope.
- API list có thể trả `content`, `files`, `user_id`, `score`, `feedback`. Chỉ render các field khi row layout và disclosure policy được duyệt; không suy tên Student, deadline hoặc rubric từ ID/copy. Secure URL/download semantics của file chưa được xác minh.
- API #54 chỉ đọc. UI không được báo mutation, “đã chấm” hay “đã đồng bộ” do riêng việc mở danh sách.

### E.3. Accessibility/design checks

- Study Web design target yêu cầu keyboard operation, focus-visible rõ, label gắn với input, accessible name cho icon-only control, state không phụ thuộc màu, control cao tối thiểu 44px, reflow đến 320 CSS px và reduced motion.
- HTML hiện gắn `label for` cho course/status/search; controls khoảng 44px. Avatar/bell và content status cần accessible name/semantics rõ; empty/loading/error announcements và row keyboard interaction chưa có.
- Footer ghi “Chuẩn kiểm định WCAG 2.1 AA” là copy, không phải kết quả audit. Không gọi màn hình đạt WCAG hoặc responsive/runtime verified trong phiên này.
