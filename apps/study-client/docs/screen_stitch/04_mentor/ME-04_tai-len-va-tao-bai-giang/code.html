3. Tóm tắt học thuật & Code Snippets mẫu

TypeScript v5.6 Ready

Trong bài giảng này, học viên tiếp cận 2 trụ cột tư duy cốt lõi:

  • Bản chất việc tự động hóa tối ưu hoá bộ nhớ (Automatic Memoization) từ trình biên dịch React Compiler thay thế cho useMemo và useCallback.
  • Xử lý triệt để hiện tượng Tearing (bất đồng bộ trạng thái luồng hiển thị) khi tích hợp Global State với Micro-Store bằng hook useSyncExternalStore.
useSyncExternalStore.example.tsx
TypeScript (TSX) 
import { useSyncExternalStore } from 'react';
import { enterpriseStore } from '@/core/store';

// Subscription contract an toàn đa luồng trên React 19 Concurrent
export function useCustomStoreSnapshot<T>(selector: (state: any) => T): T {
  return useSyncExternalStore(
    enterpriseStore.subscribe,
    () => selector(enterpriseStore.getSnapshot()),
    () => selector(enterpriseStore.getServerSnapshot())
  );
}
