### Current behavior

- Không có Study Web source, package manifest, route `/mentor`, session manager hoặc client API caller trong checkout. HTML static không có handler, mọi anchor có `href="#"`; input search chỉ có placeholder.
- Study Server hiện đăng ký cả 3 GET route. Mỗi route yêu cầu `Authorization: Bearer <access JWT>`, `sub` hợp lệ và role `MENTOR`; server chứ không phải client bảo đảm quyền truy cập.

## 3. Luồng màn hình tổng quát

1. Browser yêu cầu route đề xuất `/mentor`. Study Web hiện không có route source, nên bước mount/guard chưa được xác minh.
2. Tiền điều kiện nghiệp vụ là Mentor đã đăng nhập. Khi request tới server, #46/#54/#58 tự kiểm Bearer JWT, claims số và role `MENTOR`. Không dùng API #04 để xác minh Mentor vì API #04 yêu cầu `STUDENT`; chưa có current Mentor `/me` endpoint trong client contract này.
3. Theo inventory, dashboard cần lấy dữ liệu từ #46/#54/#58. Các request là read-only, không phụ thuộc response lẫn nhau ở backend; thứ tự/concurrency, cache và retry của client chưa được xác nhận. Không tuyên bố đã có parallel fetch.
4. Từng response phải được phân tích theo envelope thật và map riêng cho widget. `200` với empty collection là trạng thái rỗng hợp lệ. Lỗi một API không được che thành lỗi toàn màn hình nếu giữ yêu cầu widget độc lập, nhưng cách hiển thị/retry cụ thể cần thiết kế.
5. Dữ liệu #46 có thể hỗ trợ course title/description/thumbnail/price/status/mentor và tổng pagination. #54/#58 hiện không đủ projection để tái tạo nguyên các hàng mẫu. Các widget rating/lịch/thông báo/shift/profile chưa có contract và phải được giải quyết trước khi mô tả như dữ liệu động.
6. Người dùng có thể chọn điều hướng đến course, submission hoặc support. Các đích là route đề xuất; link trong HTML không hoạt động. Direct CTA tới ME-10/ME-12 chưa thống nhất với AC list-first.
7. Khi rời dashboard, không có side effect được xác nhận. Mọi GET hiện tại là read-only; không ghi cache/session/analytics theo bằng chứng trong client checkout.

## 5. Event specification

### `ME01-EV-01` — Vào dashboard và tải các widget

- **Trigger / loại:** Route entry `/mentor`; `Load` (route chỉ là expected design).
- **Element:** #2 nav current route; dữ liệu gắn với #8–#11, #12–#17.
- **Precondition:** Client auth/bootstrap chưa có source. Mỗi API yêu cầu valid Bearer access JWT có role `MENTOR`. Server guard không thay thế client login/session policy.
- **Input:** Access token từ session (nguồn/lưu trữ chưa xác minh); không có path ID. API #46 query `status?`, `page=1`, `size=20` (size 1–100); #54 `course_id?`, `status?`, `page=1`, page size cố định 20; #58 `course_id?`, `status?`, không có pagination. Không thêm `rating`, `deadline`, `unread`, `calendar` hoặc `size` cho #54/#58.
- **Xử lý tuần tự:**
  1. Chặn truy cập nếu application shell không xác định được session/role; cách redirect/login chưa có contract.
  2. Sau khi có điều kiện gọi API, request #46/#54/#58 độc lập. Backend không quy định thứ tự hoặc concurrency; client chưa tồn tại nên không được ghi “parallel” như current behavior.
  3. Với mỗi response, kiểm tra HTTP status, `success`, `businessCode`, `traceId`; chỉ map keys có trong response model. Không ánh xạ số liệu trong mockup sang API.
  4. #46: lấy `data.items` và `data.pagination`; có thể đọc `pagination.total` đúng phạm vi direct-owner và filter, chưa thể gọi là assigned count.
  5. #54: lấy `data.items`/`data.pagination`; page size cố định 20. `status` lọc exact string và không có enum validation. Chưa có căn cứ phân nhóm pending/late hoặc chọn preview size 4.
  6. #58: `data` là array không phân trang, gồm full `messages[]`/attachments. Không có summary projection; quyết định có gọi/render thread trên dashboard và giới hạn dữ liệu cần API/product agreement.
  7. Giữ `loading/empty/error` riêng từng widget; success của một API không phụ thuộc success của API khác. Cache, retry, timeout và stale-data behavior chưa được xác định.

## 6. Đặc tả API và mapping

### API #46 — Mentor-owned courses

| Thuộc tính | Current source |
|---|---|
| Method / endpoint | `GET /api/v1/mentor/courses` |
| Auth | `Authorization: Bearer <access JWT>`; role `MENTOR`; owner lấy từ numeric JWT `sub` |
| Query | `status?` enum `DRAFT`/`PUBLISHED`; `page=1`; `size=20`, range `1..100`. Dashboard không có course filter. |
| Query/effect | Đếm rồi list `courses` theo `c.mentor_id=:mentor_id`, LEFT JOIN mentor user; order `created_at DESC, id ASC`; read-only. |
| Success | HTTP 200 `DESIGN_RESOURCE_RETRIEVED`; `data.items[]`, `data.pagination{page,size,total,total_pages}`. Course fields: `id`, `title`, `description?`, `thumbnail_url?`, `price` decimal string, `status`, `mentor{id,full_name,avatar_url?}`. |
| Errors | 401 `DESIGN_AUTHENTICATION_REQUIRED`; 403 `DESIGN_ACCESS_DENIED`; 422 `DESIGN_VALIDATION_ERROR`; 500 `DESIGN_INTERNAL_ERROR`. Empty/out-of-range page là 200; `total_pages=0` khi total=0. |
| Limitation | Course “assigned” không được query; không có enrollment/progress/course-rating/count fields. API source hiện tại chưa xác minh database live. |

### API #54 — Mentor submissions list

| Thuộc tính | Current source |
|---|---|
| Method / endpoint | `GET /api/v1/mentor/submissions` |
| Auth | Bearer access JWT; role `MENTOR`; owner lấy từ numeric JWT `sub` |
| Query | `course_id?` int64 dương; `status?` exact string, không enum validation; `page=1` positive int32. Page size là 20 cố định; không gửi `size`. |
| Query/effect | Count/list qua `assignment_submissions` → `assignments` → `courses` → `users`; giới hạn `courses.mentor_id`; order `submitted_at DESC, id DESC`. Có course filter thì truy vấn course khác owner trả 403. LEFT LATERAL lookup upload candidate theo exact URL, student owner, `SUBMISSION` purpose, course. Read-only. |
| Success | HTTP 200 `DESIGN_RESOURCE_RETRIEVED`; `data.items[]`, `data.pagination{page,size=20,total,total_pages}`. Fields: `id`, `assignment_id`, `user_id`, `content?`, `files[]`, `status`, `submitted_at`, `score?` (decimal string), `feedback?`. `files[]` current mapper tối đa 1 UploadAsset. |
| Errors | 401 authentication; 403 role/other-owner course; 422 validation; 500 internal/mapping. Empty hoặc course filter không tìm thấy là 200 với trang rỗng; 409 còn trong catalog snapshot nhưng source không có current trigger. |
| Limitation | Status string không define “pending”; response không có Student summary, assignment/course title, deadline, rubric hoặc overdue policy. Assignment/upload relation là derived; test dùng fake DB, live schema chưa xác minh. |

### API #58 — Mentor support requests

| Thuộc tính | Current source |
|---|---|
| Method / endpoint | `GET /api/v1/mentor/support/requests` |
| Auth | Bearer access JWT; role `MENTOR`; owner lấy từ numeric JWT `sub` |
| Query | `course_id?` int64 dương; `status?` exact string; không pagination. Nếu course filter thuộc Mentor khác thì trả 403. |
| Query/effect | List requests theo `courses.mentor_id`; khi có rows, list toàn bộ thread/assets trong owner scope. Request order `created_at DESC,id DESC`; messages `created_at ASC,id ASC`; assets theo `asset_position`. Read-only; không gọi thread query khi collection rỗng. |
| Success | HTTP 200 `DESIGN_RESOURCE_RETRIEVED`; `data` là `SupportRequest[]`. Mỗi record có `id`, `course_id`, `student{id,full_name,avatar_url?}`, `status`, `messages[]`, `created_at`, `resolved_at?`; mỗi message có `id`, author summary, content, attachments, created_at. Empty là `[]`. |
| Errors | 401 authentication; 403 role/other-owner course; 422 invalid `course_id`; 500 query/projection failure. Course filter không tìm thấy trả `[]`/200. |
| Limitation | Không có pagination/summary/subject/unread/SLA/course title/last-message timestamp. Response chứa full message threads; support tables, lifecycle and attachment mapping are derived from checked-in migration 008. Live schema/deployment chưa xác minh. |

**Envelope:** ba API hiện dùng standard envelope `success`, `businessCode`, `message`, `data`, `meta`, `traceId`; API #46/#54 `data` chứa page; #58 `data` là array. Không chuyển #58 thành `Page<SupportRequest>` hoặc response khác dựa trên mockup.

## 7. State matrix

States dưới đây phân biệt response của từng widget với state toàn trang; chúng không tuyên bố đã có trong client.

| State | Điều kiện | UI/data behavior cần giữ | Bằng chứng / quyết định còn thiếu |
|---|---|---|---|
| `loading` per widget | Request tương ứng đang xử lý. | Một widget đang tải không được làm biến mất kết quả thành công của widget khác theo inventory. Skeleton/placeholder detail chưa có thiết kế xác nhận. | Expected từ list_screen; no runtime. |
| `ready` | API trả 200 `DESIGN_RESOURCE_RETRIEVED` và items có dữ liệu. | Chỉ map field có trong response model; không hiển thị fake counts/title/rating/SLA. | #46/#54/#58 source-backed; field mismatch còn mở. |
| `empty` | #46 page items rỗng; #54 page items rỗng; #58 `data=[]`. | Empty là success, không phải 404. Copy/CTA empty-state cần thiết kế. | Current API source. |
| `partial` | Tối thiểu một widget thành công trong khi widget khác lỗi/tải. | Giữ widget độc lập; không biến lỗi một API thành nội dung giả. | Inventory yêu cầu partial; exact shell presentation chưa có. |
| `unauthenticated` | 401 `DESIGN_AUTHENTICATION_REQUIRED`. | Handoff login/refresh/session clear chưa được quy định cho Mentor Web. | Server behavior source-backed; client behavior UNWIRED. |
| `forbidden` | 403 `DESIGN_ACCESS_DENIED` do role/course scope. | Không retry cùng token như lỗi mạng; access-denied destination/copy chưa có app router. | Server source-backed. |
| `validation-error` | 422 `DESIGN_VALIDATION_ERROR` từ query/input. | Lỗi input không được map thành empty. Dashboard không nên gửi filter không xác nhận. | #46 validator; #54/#58 route field validation. |
| `request-error` | 500 hoặc network failure. | Hiển thị lỗi độc lập với trace ID nếu có; automatic retry/timeout/stale display chưa được thiết kế. | API 500 source-backed; network UI not wired. |

## 9. Bảo mật, quyền riêng tư và accessibility

- Chỉ gọi API với Bearer token theo cơ chế Study Web được duyệt; không đưa token vào URL/query, HTML hoặc log. Current browser token storage không xác minh.
- Mọi request Mentor phải để server guard kiểm role/owner. Không dùng client course card để suy ra quyền ME-03/ME-06.
- Submission body/files và support messages là dữ liệu learner. #54 trả tới 20 submissions/page, #58 trả toàn bộ support threads không pagination; dashboard cần data minimization/summary decision trước khi tải và render nội dung nhạy cảm ở overview.
- Không sử dụng tên, avatar, score, deadline, rating, email/hotline hay meeting URL trong ảnh làm dữ liệu production.
- Khi implement, áp dụng Study Web guide: semantic button/link, accessible name cho icon-only, visible focus, keyboard tab order, text/error association, WCAG AA, target tối thiểu 44×44px, reflow 320px, `prefers-reduced-motion`. Prototype input chỉ có placeholder, icon button là 40px và không có handler; cần kiểm tra lại khi có app source.
