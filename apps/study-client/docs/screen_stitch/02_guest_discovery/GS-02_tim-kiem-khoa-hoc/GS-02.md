## 4. Đặc tả API và mapping

### 4.1. API #05 — danh mục

- Method/endpoint: public GET /api/v1/categories.
- Auth: không yêu cầu Bearer theo route source.
- Query: locale tùy chọn, kiểu string; khi bỏ qua source mặc định vi-VN. Giá trị được dùng nguyên văn để exact-match; source không trim hoặc xác thực locale syntax. Không có path/body.
- Source behavior: chọn category ACTIVE theo locale khớp chính xác, sắp xếp id ASC.
- Success: HTTP 200, business code DESIGN_RESOURCE_RETRIEVED, envelope chứa data.items và pagination. Category có id, name, slug, optional description. Empty là success; source tạo page=1, size=0, total=0, total_pages=1.
- Error: query validation trả 422; lỗi query/mapping trả safe 500 DESIGN_INTERNAL_ERROR.
- Cache/orchestration: inventory F02 yêu cầu cache-first và cho phép #07 song song nếu độc lập; AC-04 diagram/API #05 DD thể hiện #05 trước #07. Không có client cache source, TTL, invalidation, locale cache key, stale-data hoặc fallback policy; expected order cần được giải quyết.
- Quan hệ #05 → #07: metadata không cần để gọi #07 nếu category không được gửi. Có thể concurrent theo inventory khi #07 đủ điều kiện chạy; không khẳng định behavior cache/client hiện hành.

### 4.2. API #07 — tìm khóa học

- Method/endpoint: public GET /api/v1/courses/search.
- Auth: không yêu cầu Bearer theo route source.
- Query source: q optional string; page optional Python int default 1; sort optional string. Parser/model còn nhận category optional int, nhưng validator từ chối mọi giá trị non-null. `size` không được khai báo; query parameter không được khai báo (gồm size) bị FastAPI bỏ qua, không làm đổi page size.
- Validation: page phải ≥1; không có upper bound trong validator dù API catalog khai báo int32. Sort dạng `field:direction`; field hợp lệ id, name, price, created_at; direction asc, desc. Source so khớp case-sensitive và không trim sort. Invalid page/sort và category đều trả HTTP 422, business code DESIGN_VALIDATION_ERROR.
- q: trim và lowercase; chuỗi rỗng/whitespace trở thành None và bỏ predicate q. Nếu q có giá trị, query tìm LOWER(c.name) LIKE '%q%', đồng thời chỉ lấy PUBLISHED. Query parameter được bind; source không escape ký tự %/_ của LIKE.
- Ordering: mặc định created_at DESC, id ASC; sort explicit dùng builder hiện hành và tie-breaker id ASC trừ khi field sort là id. Sort input không được trim/lowercase; chỉ đúng chữ thường trong allowlist mới hợp lệ.
- Paging: DEFAULT_SIZE=20, offset (page-1)*20; không có client-selected size. Gửi size=5 không làm page size đổi thành 5.
- Query order/side effect: sau validation, source chạy COUNT trước và lấy `total` cùng `missing_mentor_count`; nếu count lỗi hoặc có PUBLISHED course thiếu mentor thì rollback/trả safe 500 và không chạy list query. Nếu hợp lệ, chạy page SELECT rồi map response. Đây là read-only flow; handler không commit.
- Success: HTTP 200, business code DESIGN_RESOURCE_RETRIEVED, data.items và data.pagination gồm page, size, total, total_pages. Empty match là items rỗng, total=0, total_pages=0. Page ngoài phạm vi là HTTP 200 với items rỗng nhưng total/total_pages giữ theo query.
- Course mapping: id, title, optional description, optional thumbnail_url, price decimal string, status, mentor gồm id, full_name, optional avatar_url. Không có category/currency/rating/duration/tags/discount/old price.
- Error: invalid query/category HTTP 422 DESIGN_VALIDATION_ERROR; query, mentor-integrity hoặc mapping failure trả safe HTTP 500 DESIGN_INTERNAL_ERROR. Mất mạng/timeout không có business code response. Retry/timeout, request cancellation, chống response cũ ghi đè state và retry policy chưa có source contract.
- API catalog trong docs/lists/list_api.md vẫn khai báo category optional và reusable Course.category; ghi đây là contract/source discrepancy. Không dùng khai báo catalog làm bằng chứng category chạy được.

  4. Đọc cache #05 trước khi gọi network nếu client cache được thiết kế; cache key/TTL/invalidation hiện chưa xác định. Cache hit/miss behavior chưa được triển khai.

  6. Kiểm tra HTTP status/business code/envelope; map items và pagination theo §4. Không biến 422/500 thành empty result.
  7. Cập nhật loading/ready/no-result/error; chỉ hiển thị field có trong response.

## 6. Ma trận trạng thái

| State | Điều kiện vào | Dữ liệu/UI | Chuyển tiếp |
|---|---|---|---|
| INITIAL_OR_PROMPT | Mở route với q vắng/rỗng | Prompt nhập từ khóa hoặc browse-all decision. Không gọi #07 cho tới khi empty-q policy được chốt. | EV-02/EV-04 → LOADING nếu query đủ điều kiện; nếu không, giữ prompt. |
| TYPING | Người dùng sửa q | Giá trị input local; expected debounce và URL sync, chưa runtime. | Hết debounce/submit → LOADING; clear → INITIAL_OR_PROMPT hoặc browse-all theo policy. |
| LOADING | #07 đang chờ; #05 có thể độc lập | Loading visual theo design chưa được mô tả đầy đủ; không hiển thị stale response như dữ liệu mới nếu chưa xác định cancellation/order. | HTTP 200 có item → READY; 200 empty total=0 → NO_RESULT; page empty total>0 → OUT_OF_RANGE; validation/internal/network → ERROR. |
| READY | #07 HTTP 200 và items không rỗng | Card fields chỉ từ Course response; pagination page size 20. Unsupported facets/card fields không được render như dữ liệu thật. | Search/sort/page change → LOADING; mở card → GS-03 proposal. |
| NO_RESULT | #07 HTTP 200, items=[], total=0 | Empty result state; exact copy/recovery chưa được chốt. Tách khỏi lỗi. | Đổi q/clear/submit → theo EV-02–04. |
| OUT_OF_RANGE | #07 HTTP 200, items=[], total>0 | Trang hiện tại ngoài phạm vi; không hiển thị như không có course. Recovery policy chưa xác định. | Page change/recovery action cần quyết định. |
| ERROR | API 422/500 hoặc network failure | Error theo status/business code; không giả làm empty state. Retry/copy chưa có UI contract. | Retry hoặc sửa input theo policy cần quyết định. |
| CATEGORY_METADATA_ERROR | #05 lỗi | Metadata categories không thể hiển thị/refresh; effect lên search independent unresolved. | Partial UI/continue/block policy cần quyết định; không suy ra #07 phải dừng nếu không cần category. |

## 7. Điều hướng, bảo mật và trải nghiệm

- **Screen flow:** GS-01 → GS-02 theo F02; GS-02 → GS-01 (quay lại danh sách) hoặc GS-03 khi mở course item. course.id là payload duy nhất đã được xác nhận từ #07 cho handoff. Các đường về/back-stack và URL preservation chưa được triển khai.
- **Public data:** #05/#07 là public endpoints. #07 giới hạn kết quả ở course PUBLISHED. Không thêm Bearer/session requirement vào API này từ screenshot account controls.
- **Data integrity:** dùng id và field từ response; không suy ra metadata chưa trả về. price là decimal string; currency formatting chưa có currency field trong response.
- **Input/query:** server dùng parameter binding; % và _ được giữ theo ngữ nghĩa LIKE hiện có do source không escape. Không thêm max length, client-side validation hay escaping policy không có trong contract.
- **Accessibility:** khi triển khai, input/select/checkbox/radio/button cần label và keyboard semantics tương ứng; trạng thái loading/error cần được công bố phù hợp. Source hiện tại không đủ để xác nhận WCAG/runtime implementation.
- **Responsive/design system:** annotation giữ nguyên bố cục nguồn. Responsive behavior và token mapping cần đối chiếu với [Study web design guide](../../../../../../.agents/web-study/design.md); không tuyên bố prototype này phù hợp guide khi source đang lệch.
- **Runtime:** không có Study Web source/package/router/entrypoint. Chưa xác minh fetch, URL sync, debounce, cache, navigation, auth shell, responsive behavior hoặc accessibility khi chạy.

## 8. Blockers và quyết định cần bổ sung

| ID | Blocker | Bằng chứng | Cần quyết định trước implementation |
|---|---|---|---|
| GS02-B01 | Source variant và actor mismatch | screen.png là loaded state, code.html là Guest empty state; header khác actor/control. | Chọn/duyệt authoritative UI và actor/header variant. |
| GS02-B02 | Facets unsupported | #07 reject category; không có skill/duration/rating/tuition query; DDL không có relation course-category. | Backend/DB/API hỗ trợ hoặc bỏ/ẩn các filter; chốt option semantics. |
| GS02-B03 | Relevance sort unsupported | Screenshot có “Phù hợp nhất”; allowlist không có relevance. | Định nghĩa mapping/score ở API hoặc thay UI sort option. |
| GS02-B04 | Page-size conflict | Screenshot 6/page; source cố định 20/page, không có size input. | Căn chỉnh design hoặc API contract/pagination. |
| GS02-B05 | Course card fields thiếu | API không trả category, currency, rating, duration, tags, discount/old price. | Chốt data/API/schema và field formatting cho từng card. |
| GS02-B06 | Empty-query semantics | AC có thể bỏ request khi rỗng; #07 blank q trả toàn bộ PUBLISHED. | Chọn prompt/no request hay browse-all. |
| GS02-B07 | Cache/partial-load/orchestration policy | AC-04 diagram/API #05 DD thể hiện #05 → #07; inventory F02 cho phép chạy song song nếu độc lập và #05 cache-first. Study Web source/cache hiện không có. | Chốt thứ tự/cache-hit behavior, cache key, TTL, invalidation, fallback và behavior khi chỉ một API lỗi. |
| GS02-B08 | Study Web UNWIRED | Không có frontend source/package/router/entrypoint trong checkout. | Có implementation surface và route wiring trước runtime verification. |
| GS02-B09 | Extra destinations | Header account, learning path, advisor và footer không có route/service contract. | Map tới screen/service owner hoặc bỏ các control khỏi scope. |

Không đóng các blocker bằng suy đoán. Đến khi các quyết định cần thiết được giải quyết, DD giữ trạng thái BLOCKED và không phải implementation-ready.
