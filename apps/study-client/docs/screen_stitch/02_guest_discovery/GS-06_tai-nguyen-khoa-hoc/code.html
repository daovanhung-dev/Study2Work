GET /courses/{course_id}/resources

Vấn đề: Response cardinality hiện đang định nghĩa trả về đối tượng Resource đơn lẻ thay vì danh sách mảng (Resource[]).

GET /resources/{resource_id}

Vấn đề: Phân định quyền truy cập Public vs Private và cơ chế ký xác thực signed URL bảo vệ dữ liệu chưa được hoàn thiện.

rule Điều kiện mở khóa giao diện người dùng (Hand-off Unblock Criteria):
  • API #11 cần trả schema: { items: Resource[], total: number }.
  • API #12 cần cung cấp URL có chữ ký điện tử thời hạn kèm cơ chế phân quyền RBAC cho học viên đã đăng ký hợp lệ.
  • Mọi request tải tài liệu phải thông qua gateway có gắn token phân quyền.

State Inventory

4 States

Chỉ dẫn thiết kế chi tiết cho lập trình viên FE/BE khi API chuyển trạng thái Ready:

1. Trạng thái Empty (Hiện tại) Active

Hiển thị khi khóa học chưa có tài nguyên hoặc khi đang bị chặn do chưa chốt chữ ký xác thực API #11 & #12.

2. Trạng thái Danh sách (List) Chờ API

Áp dụng bảng liệt kê có phân loại: Bài giảng, Code mẫu, Sách tham khảo. Chỉ kích hoạt khi API #11 trả về danh sách mảng.

3. Trạng thái Không có quyền (Forbidden) HTTP 403

Hiển thị thông báo yêu cầu học viên đăng ký hoặc xin quyền từ Mentor đối với tài liệu học tập đóng kín (Private).

4. Liên kết hết hạn (Expired-Link) HTTP 410

Xảy ra khi signed URL hết hạn hợp lệ sau phiên làm việc (TTL timeout). Cung cấp nút "Yêu cầu tạo lại liên kết tải".
