Technical Gate G-03

Tài liệu chẩn đoán dành cho Backend Core & Database Admin về các blocker trên Route /student/profile/edit:

1. API #13 POST /users/me/avatar Asset Mismatch

Xung đột schema avatar asset: Frontend yêu cầu CDN multipart/form-data upload, nhưng DDL 18 bảng hiện tại chỉ lưu trữ chuỗi VARCHAR thô chưa có asset metadata handler.

2. API #14 PUT /users/me/profile DDL Missing Fields

Trường bio không tồn tại trong DDL 18 bảng DB.sql. Cột phone có trạng thái nullable nhưng thiếu validation regex và quy tắc lưu đồng bộ.
