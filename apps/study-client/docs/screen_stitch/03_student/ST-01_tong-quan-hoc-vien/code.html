Tổng quan học tập

Không gian hiển thị tổng quan tiến trình đào tạo nghề nghiệp cá nhân. Hiện tại, toàn bộ dịch vụ dữ liệu học viên (học phần, thống kê hoàn thành, danh hiệu và bản tin) đang trong giai đoạn hoàn thiện hợp đồng giao tiếp API với backend. Trạng thái kiểm thử tuân thủ nghiêm ngặt nguyên tắc cổng kiểm soát, không phát sinh số liệu nhân tạo.
