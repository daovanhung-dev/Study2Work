## A. Tổng quan màn hình

### Mục tiêu và expected behavior

AD-13 là trang Admin xem chi tiết một lesson đã chọn từ AD-12. Inventory row 71 đề xuất route `/admin/lessons/:lessonId`, GET #83 và xem lesson content/status/linked progress theo contract; AC-34 mô tả AD-12 list → AD-13 detail → một nhánh tại AD-14 (update #84, status #85 hoặc delete #86) → reload AD-12. Path #83 yêu cầu `lesson_id:int64`; dữ liệu handoff ứng viên là numeric `Lesson.id` từ row list. API #82 catalog hiện ghi một `Lesson`, còn local #82 trả collection; cần giữ discrepancy từ AD-12 khi chốt client mapping.

AC-34 node n5 ghi “Đọc lesson + dependencies”, nhưng không xác định dependency fields, counts, schema hay vị trí response. API #83 catalog trả `ApiEnvelope<Lesson>` trực tiếp, không khai báo dependencies. Đây là blocker để màn hình không tự trình bày progress/resource counts.

### Current behavior đã xác minh

- **Study Web:** thư mục hiện có `docs`, ignored `dist`, `node_modules` và `tsconfig.tsbuildinfo`; không có editable `src`, `package.json`, router hoặc API client. `code.html` không có route param/data binding, request, `EventSource`, WebSocket, timer hay listener. Anchors dùng `href="#"`; action tới AD-14 là button disabled. Study Web `UNWIRED`; không có runtime verification.
- **API #83:** local route `GET /api/v1/admin/lessons/{lesson_id}`, `GetAdminLessonEnvelope`, direct `Lesson` response. Bearer/JWT shared guard yêu cầu role `ADMIN` trước custom raw-path parsing và DB. AC-34 lesson-management permission chưa được enforce bởi route source đã rà soát.
- `lesson_id` custom parser nhận signed int64 trong bounds; malformed, overflow hoặc raw path dài hơn 20 ký tự trả 404 `DESIGN_RESOURCE_NOT_FOUND` (local DERIVED choice để khớp error set; không gọi DB). Parser không tạo 422.
- Bound query lấy tối đa một row từ candidate legacy `lessons` theo `id`, loại `status='DELETED'`; không áp dụng public `PUBLISHED` filter. Không join `courses`, không đọc `resources`/`lesson_progress`, không trả pagination/dependency data, không ghi hoặc commit.
- Mapping dùng reusable API #09 `Lesson`: `id`, `course_id`, `name→title`, nullable `content`, nullable `video_url`, `sort_order→order`, `status`. Success HTTP 200 trả direct `data` object, `meta:{}` và trace ID. Row thiếu/mismatch hoặc required projection không hợp lệ→safe 500 + rollback; row vắng mặt/tombstone→404 + rollback; query error→safe 500 + rollback. Optional `content`/`video_url` null serialize thành JSON `null`.
- Test source API #83 đã đọc, không chạy trong phiên này. Source tests dùng fake DB; historical API DD report ghi 15 focused passes nhưng không chứng minh live PostgreSQL/schema/deployment.
- API #83 DD là `Draft — Needs Confirmation`. Legacy `lessons` DDL dùng BIGINT và cho phép nullable `course_id`, `sort_order`, `status`, trong khi Lesson response yêu cầu các field đó. V1-PILOT DDL dùng UUID/versioned lesson model với field khác; live schema chưa được xác minh.

## B. Luồng hoạt động tổng thể

1. **Đi vào từ AD-12:** expected flow chọn lesson trong AD-12 rồi truyền `Lesson.id` số nguyên vào `/admin/lessons/:lessonId`. Inventory và API #83 xác nhận path numeric; current AD-12 table/action chưa có row data và client route chưa tồn tại. Không truyền course slug/title thay lesson ID.
2. **Kiểm tra phiên/quyền:** target client cần session Admin. Request #83 hiện xác thực Bearer/JWT + claim `ADMIN` trước khi parse raw path hay truy vấn DB. AC-34 yêu cầu lesson-management permission riêng nhưng source chỉ có role guard; không để UI badge thay quyền server.
3. **Chuẩn bị request:** tạo `GET /api/v1/admin/lessons/{lesson_id}` với Bearer token; không body/query. Giữ numeric ID; client không tự đặt positive constraint ngoài nguồn. API raw parser chấp nhận signed int64 text và leading zero trong giới hạn parser.
4. **Lookup:** server bind ID vào `FIND_ADMIN_LESSON_DETAIL`; đọc một row từ candidate legacy `lessons`; loại `status='DELETED'`; không lọc `PUBLISHED`, không join course/resources/progress và không gọi metric API.
5. **Xử lý response:** success trả `ApiEnvelope<Lesson>` trực tiếp; map `id`, `course_id`, `title`, `content`, `video_url`, `order`, `status`. `content` và `video_url` có thể null. `course_id/order/status` required ở model nhưng legacy DDL có thể NULL; lỗi map hiện thành 500 + rollback.
6. **Render:** prototype hiện luôn hiển thị no-selection placeholders. Target UI chỉ render fields response-backed sau khi contract/schema được giải quyết; `course_id` là ID, không phải course title; status cần giữ raw hoặc chờ enum mapping. No resource/progress/metrics fields are present in #83.
7. **Media/resources:** `content` là nullable string, không có HTML sanitization/rendering contract trong #83; `video_url` là nullable string, không có signed URL/player policy. Resources/quiz/discussion cards và số liệu không thể bind từ response.
8. **Hành động:** button tới AD-14 hiện disabled. Khi workflow được wire, chuyển cùng `lessonId` đến AD-14; không gọi #84/#85/#86 từ AD-13. API #86 tự kiểm tra progress/resources/uploads khi thực hiện delete.
9. **Rời màn hình:** expected back-to-AD-12 link. Current anchors là `#`; browser history, query preservation, refetch sau AD-14 và chọn lại row chưa được định nghĩa.

### Response và lỗi

- **Request:** `GET /api/v1/admin/lessons/{lesson_id}`, `Authorization: Bearer <token>`; optional `X-Trace-Id` theo middleware; no query/body.
- **Success:** HTTP 200; `success`, `businessCode=DESIGN_RESOURCE_RETRIEVED`, message, `data: Lesson`, `meta:{}`, `traceId`. Local message hiện là “Lesson retrieved.”.
- **Errors:** 401 `DESIGN_AUTHENTICATION_REQUIRED`; 403 `DESIGN_ACCESS_DENIED`; 404 `DESIGN_RESOURCE_NOT_FOUND` cho invalid/overflow/overlength ID hoặc missing/DELETED row; 500 `DESIGN_INTERNAL_ERROR` cho DB/mapping/required projection error.
- **Rollback/commit:** no commit on success. Missing row and error projection/query paths call rollback. Test source checks safe envelope and no raw database details.
- **Retry/cache/timeouts:** không có Study Web client policy; chưa được thiết kế. Không khẳng định stale response, request cancellation, retry hoặc cache invalidation.

## D. Đặc tả chi tiết sự kiện

Prototype không implement các event sau; đây là target flow và source trace. Không có client retry/cache/timeout policy để ghi thành current behavior.

### EV-01 — Mở route và tải lesson detail

- **Trigger / element:** điều hướng từ row selection AD-12 tới route `/admin/lessons/:lessonId`; #16/#25/#44. **Type:** Load/navigation.
- **Precondition:** Admin session; expected lesson-management permission. Current server only enforces role `ADMIN`.
- **Input:** numeric `Lesson.id` từ response #82 → route param `lessonId` → path `lesson_id:int64!`; Bearer JWT; optional trace header. No body/query.
- **Processing:** (1) Client target xác nhận path param có mặt; absent-route fallback chưa xác định. (2) Gửi GET #83 với ID đã chọn, không thay bằng course ID/slug. (3) Shared server guard xác thực Bearer/JWT/`ADMIN` trước parse/DB. (4) Custom parser chấp nhận signed int64 string có dấu/leading zeros trong bounds; invalid/overflow/length>20→404 catalog code, no query. (5) Bind numeric ID vào query. (6) Select một lesson từ legacy candidate, `status IS DISTINCT FROM 'DELETED'`; không public `PUBLISHED` filter/dependency joins. (7) Validate returned identity/required Lesson fields. (8) Trả 200 direct Lesson hoặc exact errors.
- **Success:** `ApiEnvelope<Lesson>`; UI target nhận `data.id`, `course_id`, `title`, `content`, `video_url`, `order`, `status`. #83 không cập nhật DB/commit.
- **Errors:** 401, 403, 404 invalid/missing/deleted, 500 safe query/projection. Query/mapping/missing branches rollback per source.
- **UI state:** expected loading→ready; 404→not-found; 401→unauthorized; 403→forbidden; 500/network→service-error. These states have no client implementation.

### EV-02 — Ánh xạ và hiển thị Lesson

- **Trigger / element:** successful EV-01 response; #22–#33.
- **Input:** exact `Lesson` object from #83. `course_id/order/status` are required in response model; `content`/`video_url` may be JSON null.
- **Processing:** map `id→lesson identifier`, `title→title`, `course_id→course ID`, `order→chapter order`, `status→raw status`. Do not map course name or content type because the fields are absent. Null content/video remains null; do not display static `--` as server value. If required projection fails server returns 500, rather than dropping the row or filling defaults.
- **Output:** target ready view may show only fields and labels approved by product. Status vocabulary/casing and course display rules need confirmation. Legacy DDL nullability mismatch remains open.

### EV-03 — Render content or video/media preview

- **Trigger / element:** content/video cards #24–#26 and #38 after a successful detail response.
- **Input:** nullable `data.content:string` and `data.video_url:string`; no other payload or signed locator.
- **Processing:** #83 only reads/returns string fields.
