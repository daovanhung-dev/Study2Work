## A. Tổng quan màn hình

### Mục tiêu và expected behavior

AD-12 là danh sách bài học trong vùng quản trị đào tạo. Inventory row 70 đề xuất route `/admin/lessons`, Admin có quyền quản lý bài học, lọc danh sách theo khóa học/trạng thái/loại, mở chi tiết AD-13 và tiếp tục sang AD-14 cho update/status/delete. AC-34 mô tả chuỗi API #82 list → #83 detail → #84 update, #85 status hoặc #86 delete → reload list. Đây là expected design; Study Web chưa có route/caller để xác minh.

Catalog #82 quy định `GET /api/v1/admin/lessons`, Bearer/Admin, query tùy chọn `course:int64`, `status:string`, `type:string`, response `ApiEnvelope<Lesson>` (singular), lỗi 401/403/500. Local route hiện trả `ApiEnvelope<Lesson[]>`; catalog cardinality cần được chủ contract giải quyết. API #82 DD vẫn `Draft — Needs Confirmation`.

### Current behavior đã xác minh

- Trong checkout hiện tại không có editable Study Web `src`, `package.json`, router hoặc API client. `code.html` là prototype tĩnh, anchor dùng `href="#"`, controls không có event handler/data binding; không tìm thấy `fetch`/XHR/API URL/timer. Trạng thái: `UNWIRED`; không có runtime evidence.
- API #82 có route/module/query/model và test source. Shared Bearer/JWT role guard chỉ xác nhận `ADMIN`, chạy trước query parsing/DB; không chứng minh lesson-management permission của AC-34.
- `course` nhận signed int64 gồm giá trị âm/0; sai kiểu/overflow trả 422. Bất kỳ `type` được gửi nào, kể cả empty string, trả 422 `DESIGN_VALIDATION_ERROR` / `UNSUPPORTED_FILTER`. `status` được dùng như chuỗi exact, không enum/normalize/whitelist.
- Query đọc candidate legacy BIGINT `lessons`, lọc equality tùy chọn `course_id`/`status`, bỏ `status='DELETED'`, sắp theo `course_id ASC NULLS LAST, sort_order ASC NULLS LAST, id ASC`; không join, type filter, total, pagination hay mutation. Empty result là HTTP 200 `data: []`.
- Local response là `ApiEnvelope<Lesson[]>`, direct `data` list. Các trường map: `id`, `course_id`, `name→title`, nullable `content`, nullable `video_url`, `sort_order→order`, `status`. DDL legacy cho phép `course_id`, `sort_order`, `status` NULL dù response yêu cầu non-null; projection không hợp lệ trở thành safe 500 + rollback.
- Checked-in DDL không xác nhận live schema/deployment. BIGINT legacy model khác V1-PILOT UUID model. API tests dùng fake DB; test source đã đọc, không chạy trong phiên này.

### Tác nhân, điều kiện và bảo mật

- **Actor dự kiến:** Admin có lesson-management permission theo AC-34. **Current API:** role `ADMIN`; permission chi tiết chưa có bằng chứng.
- **Precondition thiết kế:** authenticated session, authorization hợp lệ, route `/admin/lessons`; option/query mapping chỉ được bật khi contract xác nhận. Current backend chạy authorization trước parse filter và truy cập DB.
- **Postcondition:** chỉ hiển thị collection đọc được; #82 không thay đổi dữ liệu. Mở AD-13 là điều hướng thiết kế bằng numeric `Lesson.id` nếu server trả về một row.
- Không coi badge `RBAC`, `SYSTEM NORMAL`, “API #82 Endpoint Active”, “Đồng bộ trực tiếp từ CSDL LMS” là kết quả kiểm tra runtime hoặc health/DB signal.

## B. Luồng hoạt động tổng thể

1. **Vào màn hình:** expected Admin mở route `/admin/lessons`, có thể từ vùng Admin hoặc sau khi quay lại từ AD-13/AD-14. Route/client chưa tồn tại trong checkout; HTML preview không xử lý navigation.
2. **Authentication/authorization:** client target cần session hợp lệ. Với request #82 hiện tại, shared Bearer/JWT `ADMIN` guard chạy trước parse query và DB. 401/403 là server outcomes; AC-34 permission riêng chưa được kiểm tra bởi source đã rà soát.
3. **Khởi tạo filter:** mockup trình bày keyword, course, type và status. Không có default/query state client source. Chỉ `course`/`status` có đường xử lý local; `type` hiện bị từ chối. Không giả định UI slug/alias hoặc giá trị mặc định.
4. **Gọi API:** API contract dự kiến #82 `GET /api/v1/admin/lessons`; gửi Bearer token và chỉ query đã được xác nhận. Catalog cho phép `course`, `status`, `type`; current source không nhận được một `type` hợp lệ nào. Không có body. Không có retry/timeout/idempotency/cache policy từ client source.
5. **Xử lý query:** backend parse `course` thành signed int64; bind exact optional `course_id`/`status`; SQL loại `DELETED` và áp dụng thứ tự xác định. Không pagination/count/type/search/join.
6. **Xử lý response:** local success là 200 `ApiEnvelope<Lesson[]>` với list trong `data`; map `name→title`, `sort_order→order`. Empty list là `[]`. Catalog singleton khác local response. Required projection có thể fail nếu legacy row chứa NULL ở `course_id/order/status`, tạo safe 500 + rollback.
7. **Render UI:** current HTML luôn là empty-state prototype; không bind API. Tương lai chỉ có thể render fields response-backed sau khi owner giải quyết cardinality, filter mapping, nullability, access và pagination. Empty server result không chứng minh dữ liệu đang chờ đồng bộ.
8. **Tương tác:** refresh/reset cần gọi lại #82 sau khi filter contract rõ; search/type/status mapping hiện bị chặn. CTA Add không có API. Khi có row, `Lesson.id` là dữ liệu handoff candidate tới AD-13/#83; không mô tả action ngoài contract.
9. **Rời màn hình:** expected AD-13 detail → AD-14 actions → reload #82 theo AC-34. Lịch sử, giữ filter, stale data, row action placement, back behavior và reload strategy chưa được xác nhận.

### Request/response và lỗi #82

- **Request:** `GET /api/v1/admin/lessons`; `Authorization: Bearer <token>`; query `course?: int64`, `status?: string`, `type?: string`; không body. Catalog định nghĩa các query nhưng chưa giải quyết local behavior `type`.
- **Success theo catalog:** `200 ApiEnvelope<Lesson>` (singular).
- **Success theo local source:** `200 ApiEnvelope<Lesson[]>`, direct array `data`; không metadata phân trang.
- **Local error behavior:** 401 unauthenticated, 403 role không hợp lệ; `course` sai/overflow hoặc `type` supplied → 422 `DESIGN_VALIDATION_ERROR`; query/row mapping/projection lỗi → safe 500 và rollback. Không có path param nên #82 không có 404.
- **Retry/timeout/dedup/cache:** chưa có Study Web caller hoặc policy source; để mở, không khẳng định.

## D. Đặc tả chi tiết sự kiện

Prototype chưa phát sinh các event dưới đây; đây là event design và source trace, không phải behavior đang chạy. Trình tự chỉ gồm bước được áp dụng; client-side retry/timeout/cache policy để mở vì không có client source.

### EV-01 — Vào màn hình và tải danh sách

- **Trigger / element:** route entry/reload AD-12; #14/#25–#34. **Type:** Load.
- **Precondition:** expected authenticated Admin có lesson-management permission; hiện chỉ local role `ADMIN` evidence. Route `/admin/lessons` là đề xuất.
- **Input:** optional query `course?:int64`, `status?:string`, `type?:string` theo catalog; no body. Mockup keyword/slug/status alias không được tự thêm vào request.
- **Processing:** (1) UI target bắt đầu `loading`; không có client implementation hiện tại. (2) Gọi #82 với Bearer và query đã được duyệt. (3) Server kiểm tra JWT/role trước query parse/DB. (4) Parse `course` thành signed int64; supplied `type` bị validator từ chối 422, kể cả chuỗi rỗng. (5) Query active candidate legacy `lessons`, exact equality course/status, bỏ `DELETED`, order `course_id ASC NULLS LAST, sort_order ASC NULLS LAST, id ASC`. (6) Map row theo response `Lesson`; không pagination/count. (7) Local success trả `200 ApiEnvelope<Lesson[]>` `data` là array; catalog lại ghi singular. (8) UI target cần xử lý envelope/cardinality sau khi contract thống nhất.
- **Output/state:** non-empty list có thể thành `ready`; empty `[]` thành `empty`; hiện screenshot luôn hiển thị static empty. Không suy ra “sync pending”.
- **Errors:** 401/403; 422 malformed/overflow `course` hoặc any supplied `type`; safe 500 + rollback query/mapping/null projection failure. Catalog chưa liệt kê 422. #82 không có 404 path.
- **API details:** `GET /api/v1/admin/lessons`, Bearer/Admin theo catalog; query như trên; no request body; expected response catalog `ApiEnvelope<Lesson>`, actual local `ApiEnvelope<Lesson[]>`; timeout/retry/dedup/cache chưa có policy.

### EV-02 — Nhập từ khóa tìm kiếm

- **Trigger / element:** input #20, input/change/submit tùy client design; current HTML không có handler.
- **Input:** text placeholder gợi ý tên bài hoặc mã bài giảng; giới hạn/normalization/debounce/submit mode không được quy định.
- **Processing:** không gửi `q`, `keyword` hoặc code tới #82 vì route không khai báo query tương ứng; `Lesson` projection cũng không có lesson code. Giữ query chưa áp dụng hoặc disable input cho tới khi owner bổ sung contract và source.
- **Output/errors:** không có filter result hiện tại. Không tuyên bố 0 matches hay tự client-filter toàn bộ list khi chưa có cap/paging semantics. Validation, debounce, request cancellation và empty-query behavior là open decisions.

### EV-03 — Chọn khóa học

- **Trigger / element:** change #21; hiện select trong static HTML.
- **Input:** UI option slug (ví dụ `fe`, `be`, `ux`, `qa` trong prototype); API query cần `course` signed int64, đại diện candidate `Course.id`.
- **Processing:** chưa có mapping slug→int64 hoặc option API được duyệt. Không gửi slug vào int64, không suy ra ID, không gọi API khác để tạo mapping. Sau khi source/mapping được phê duyệt, client có thể gửi đúng numeric `course`; current server accepts signed int64 including negative/zero, rejects invalid/overflow with 422 after auth.
- **Output/errors:** chỉ render filtered data sau response #82 contract resolution; local errors 401/403/422/500. Mapping, empty option và reset default cần chốt.

### EV-04 — Chọn loại bài học

- **Trigger / element:** change #22.
- **Input:** prototype options `video`, `reading`, `assignment`, `quiz`.
- **Processing:** model/query/DDL candidate không cung cấp lesson type; mọi `type` hiện có trong query trả `422 DESIGN_VALIDATION_ERROR`, field `type`, code `UNSUPPORTED_FILTER`. Không gửi param hoặc ánh xạ sang field khác cho tới khi owner bổ sung contract.
- **Output/errors:** không có filtered state theo type ở current source. UI không được hiển thị thành công như thể filter đã áp dụng; cần thống nhất enum, data source, migration/query và catalog.

### EV-05 — Chọn trạng thái

- **Trigger / element:** change #23.
