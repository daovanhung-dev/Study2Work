# Danh mục endpoint Study API

> **Nguồn và phạm vi:** đủ 103 API ID (1–103) theo [catalog thiết kế](../../../docs/lists/list_api.md) và DD tương ứng trong `apps/study-server/docs/dd/`. Tên hiển thị lấy từ DD Cover khi có; method/path và contract I/O lấy từ catalog được duyệt.
>
> **Lưu ý runtime:** đây là danh mục theo thiết kế/DD, không xác nhận endpoint đã được wire hoặc hoạt động trong runtime. Trạng thái DD giữa các API không đồng nhất; nhiều DD còn Draft hoặc có nội dung DERIVED cần xác nhận.
>
> **Envelope và lỗi:** thành công dùng `ApiEnvelope<T>` (`success`, `businessCode`, `message`, `data`, `meta`, `traceId`). Cột đầu ra ghi HTTP thành công, business code và kiểu `data`; lỗi dùng envelope chung với `success=false`, status/code tùy từng API theo catalog (thường gồm 401, 403, 404, 409, 422, 500 và 503).
>
> **Header:** Authorization theo từng dòng; body JSON dùng `Content-Type: application/json`, còn multipart được ghi riêng. Header bổ sung như `X-Trace-Id`/`Idempotency-Key` chỉ được nêu nếu DD endpoint khai báo.
>
> **DISCREPANCY:** một số Cover bỏ trống method hoặc route (#44, #63, #76, #94–#103), và Cover thiếu tên API ở #76, #94–#103; các ô này dùng catalog. API #49–#50 thiếu Purpose trong Overview nên ghi rõ chưa được đặc tả.
