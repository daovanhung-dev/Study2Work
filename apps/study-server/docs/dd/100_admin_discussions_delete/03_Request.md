# Request

## Phạm vi input

`DELETE /api/v1/admin/discussions/{discussion_id}` nhận Bearer JWT và một path parameter bắt buộc theo catalog #100. Catalog không khai báo query hoặc request body.

## Header

| Header | Required | Type | Mục đích | Basis/status |
|---|---:|---|---|---|
| `Authorization` | Yes | `Bearer <JWT>` | Xác thực principal Admin | DIRECT; Admin claim/guard SOURCE_REQUIRED |

Catalog không khai báo `Content-Type` hoặc header tùy chỉnh khác. `X-Trace-Id` thuộc API guideline chung, không phải field riêng của catalog #100.

## Path parameters

| Name | Required | Type | Default | Description/use | Validation / unresolved |
|---|---:|---|---|---|---|
| `discussion_id` | Yes | int64 | Không nêu | Chọn discussion cần xóa mềm | Kiểu DIRECT; parse/overflow mapping và range chưa được nêu |

## Query parameters

Không có query parameter. Không nhận thêm `reason`, `action`, `page` hoặc `severity` từ API #97/#99.

## Request body

Không có request body theo catalog. API #100 không nhận `reason`; body `reason` của #99 chỉ giải thích hành động moderation.

## Ví dụ request

```text
DELETE /api/v1/admin/discussions/123
Authorization: Bearer <JWT>
```

`123` chỉ minh họa path int64, không biểu thị record tồn tại, role token, hay trạng thái được phép xóa.
