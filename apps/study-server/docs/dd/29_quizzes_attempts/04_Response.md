## Ví dụ thành công

~~~json
{
  "success": true,
  "businessCode": "DESIGN_RESOURCE_CREATED",
  "message": "Attempt created (illustrative text).",
  "data": {
    "id": 9001,
    "quiz_id": 501,
    "status": "IN_PROGRESS",
    "started_at": "2026-10-12T08:30:00Z",
    "answers": []
  },
  "meta": {},
  "traceId": "00000000-0000-4000-8000-000000000029"
}
~~~

The empty answers array and message text are illustrative; confirm the initial response shape and message policy before approval. submitted_at and score are omitted because they are optional in the logical schema; whether to omit them or return null is open.

## Ví dụ lỗi

Error example illustrates the envelope only. Exact condition-to-code mapping and message text are not settled.
