## Ví dụ Request data

~~~http
POST /api/v1/assignments/1001/submissions
Authorization: Bearer <student-token>
Content-Type: application/json

{
  "text": "Illustrative submission text",
  "file refs": "<file-reference representation: SOURCE_REQUIRED>"
}
~~~

> The JSON is syntactically valid and preserves the catalog token. It does not establish that a JSON property containing a space is the final wire name or that file references are encoded as one string.

## Request summary

- assignment_id: int64, required path parameter.
- text: string, required.
- file refs: string, required catalog notation; wire key and representation SOURCE_REQUIRED.
- No request field for user_id is defined; actor identity comes from the Bearer principal.
