# Response

## Format

| Thuộc tính | Giá trị |
|---|---|
| Format | `JSON` |
| Character encoding | `UTF-8` |
| Content-Type | `application/json` |

## Response fields

| No | Path | Logical name | Physical name | Type | Nullable | Source table | Source column | Source step | Transform | Null/empty/omit rule | Remarks |
|---:|---|---|---|---|---:|---|---|---|---|---|---|
| 1 | `HTTPStatus` | HTTP Status | `HTTPStatus` | `integer` | `No` | `N/A` | `N/A` | `8.1` | Fixed by branch | `N/A` | Success `201`; validation `422`; conflict `409`; system `500` |
| 2 | `success` | Success flag | `success` | `boolean` | `No` | `N/A` | `N/A` | `8.1/8.2` | `true` on success, `false` on error | `N/A` | `ApiEnvelope` field |
| 3 | `businessCode` | Business code | `businessCode` | `string` | `No` | `N/A` | `N/A` | `8.1/8.2` | Fixed by branch | `N/A` | Uses `DESIGN_*` code from contract |
| 4 | `message` | Message | `message` | `string` | `No` | `N/A` | `N/A` | `8.1/8.2` | Fixed by branch | `TBD — message text chưa đặc tả` | No secret or raw DB detail |
| 5 | `data` | User profile | `data` | `object` | `No` | `users` | `N/A` | `8.1` | `UserProfile` mapping | `{}` on error | Success payload |
| 5.1 | `data.id` | User ID | `id` | `int64` | `No` | `users` | `id` | `8.1` | BIGSERIAL serialized as int64 | `N/A` | Generated by DB |
| 5.2 | `data.full_name` | Full name | `full_name` | `string` | `No` | `users` | `full_name` | `8.1` | Direct mapping | `N/A` | |
| 5.3 | `data.email` | Email | `email` | `email` | `No` | `users` | `email` | `8.1` | Direct mapping | `N/A` | |
| 5.4 | `data.role` | Role | `role` | `string` | `No` | `users` | `role` | `8.1` | Default `STUDENT` | `N/A` | |
| 5.5 | `data.avatar_url` | Avatar URL | `avatar_url` | `uri` | `Yes` | `users` | `avatar_url` | `8.1` | Direct mapping | `TBD — null/omit rule chưa đặc tả` | Optional contract field |
| 5.6 | `data.bio` | Biography | `bio` | `string` | `Yes` | `N/A` | `N/A` | `8.1` | `DISCREPANCY — no ERD source` | `TBD — null/omit rule cần xác nhận` | Contract field has no `users` column |
| 5.7 | `data.phone` | Phone | `phone` | `string` | `Yes` | `users` | `phone` | `8.1` | Direct mapping | `TBD — null/omit rule chưa đặc tả` | Optional contract field |
| 5.8 | `data.status` | Account status | `status` | `string` | `No` | `users` | `status` | `8.1` | DB default `ACTIVE` | `N/A` | |
| 5.9 | `data.created_at` | Created time | `created_at` | `date-time` | `No` | `users` | `created_at` | `8.1` | Direct mapping | `N/A` | Timestamp generator TBD |
| 5.10 | `data.updated_at` | Updated time | `updated_at` | `date-time` | `No` | `users` | `updated_at` | `8.1` | Direct mapping | `N/A` | Timestamp generator TBD |
| 6 | `meta` | Metadata | `meta` | `object` | `No` | `N/A` | `N/A` | `8.1/8.2` | Empty object | `{}` | `ApiEnvelope` field |
| 7 | `traceId` | Trace ID | `traceId` | `uuid` | `No` | `N/A` | `N/A` | `8.1/8.2` | Request correlation/generator | `TBD — exact generator chưa đặc tả` | `ApiEnvelope` field |

> Error response dùng các field `success`, `businessCode`, `message`, `data`, `meta`, `traceId` của `ApiEnvelope`; contract không đặc tả `error_code` hoặc `error_message_id` riêng.
>
> `HTTPStatus` trong bảng là protocol status, không phải property JSON của `ApiEnvelope`.

## Ví dụ thành công

```json
{
  "success": true,
  "businessCode": "DESIGN_RESOURCE_CREATED",
  "message": "Account created",
  "data": {
    "id": 1001,
    "full_name": "Nguyen Van A",
    "email": "student@example.com",
    "role": "STUDENT",
    "status": "ACTIVE",
    "created_at": "2026-08-28T00:00:00Z",
    "updated_at": "2026-08-28T00:00:00Z"
  },
  "meta": {},
  "traceId": "00000000-0000-0000-0000-000000000001"
}
```

## Ví dụ lỗi

```json
{
  "success": false,
  "businessCode": "DESIGN_STATE_CONFLICT",
  "message": "Email already exists",
  "data": {},
  "meta": {},
  "traceId": "00000000-0000-0000-0000-000000000002"
}
```
