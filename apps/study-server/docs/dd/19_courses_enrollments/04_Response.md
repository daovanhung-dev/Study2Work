# Response

## Format

| Thuộc tính | Giá trị |
|---|---|
| Format | JSON |
| Character encoding | UTF-8 |
| Content-Type | application/json |
| Success HTTP status | 201 |
| Success business code | DESIGN_RESOURCE_CREATED |

## Response fields

| No | Path | Logical name | Physical name | Type | Nullable | Source table | Source column | Source step | Transform | Null/empty/omit rule | Remarks |
|---:|---|---|---|---|---:|---|---|---|---|---|---|
| 1 | HTTPStatus | HTTP status | HTTPStatus | integer | No | N/A | N/A | 5.1 | Fixed by success branch | N/A | API #19 row declares HTTP 201. |
| 2 | success | Success flag | success | boolean | No | N/A | N/A | 5.1 | true on success | Required by ApiEnvelope<T>. | Design contract; API #19 runtime is unwired. |
| 3 | businessCode | Business code | businessCode | string | No | N/A | N/A | 5.1 | DESIGN_RESOURCE_CREATED | N/A | Directly declared by API #19. |
| 4 | message | Response message | message | string | No | N/A | N/A | 5.1 | SOURCE_REQUIRED | N/A | API-specific message text is not specified. |
| 5 | data | Enrollment | data | Enrollment | No | Logical Enrollment | N/A | 5.1 | Object mapping per reusable schema | Required on success. | Physical query/result source is not implemented. |
| 5.1 | data.id | Enrollment ID | id | int64 | No | enrollments | id | 4.1/5.1 | Generated by BIGSERIAL in checked-in DDL; runtime source SOURCE_REQUIRED. | Required by Enrollment schema. | DB.sql is design evidence only. |
| 5.2 | data.course_id | Course ID | course_id | int64 | No | enrollments | course_id | 1.2/4.1/5.1 | From the request after path/body reconciliation. | Required by Enrollment schema. | Request precedence/equality rule unresolved. |
| 5.3 | data.user_id | User ID | user_id | int64 | No | enrollments | user_id | 0.2/4.1/5.1 | JWT identity mapping SOURCE_REQUIRED. | Required by Enrollment schema. | Catalog says user from JWT:string; current Study helper parses numeric sub to int. |
| 5.4 | data.status | Enrollment status | status | EnrollmentStatus | No | enrollments | status | 4.1/5.1 | SOURCE_REQUIRED | Required by Enrollment schema. | Enum values and initial status are not specified; SQL default ACTIVE is design-only evidence. |
| 5.5 | data.enrolled_at | Enrollment time | enrolled_at | date-time | No | enrollments | enrolled_at | 4.1/5.1 | ISO-8601 per API convention; value source SOURCE_REQUIRED. | Required by Enrollment schema. | DB.sql declares NOT NULL without a default. |

## Ví dụ thành công

Values below illustrate the response shape. The EnrollmentStatus string and message are placeholders; ACTIVE is not approved as API #19's initial status by this example.

~~~json
{
  "success": true,
  "businessCode": "DESIGN_RESOURCE_CREATED",
  "message": "<MESSAGE: not specified>",
  "data": {
    "id": 7001,
    "course_id": 101,
    "user_id": 42,
    "status": "<EnrollmentStatus: SOURCE_REQUIRED>",
    "enrolled_at": "2026-10-11T10:00:00Z"
  },
  "meta": {},
  "traceId": "00000000-0000-4000-8000-000000000019"
}
~~~

## Ví dụ lỗi

Example uses the declared 409 state-conflict code. The current shared Study error helper's envelope shape is shown for reference; API #19 has no runtime implementation, and the exact 409 condition remains unresolved.

~~~json
{
  "success": false,
  "businessCode": "DESIGN_STATE_CONFLICT",
  "message": "<MESSAGE: not specified>",
  "data": {},
  "meta": {},
  "traceId": "00000000-0000-4000-8000-000000000019"
}
~~~
