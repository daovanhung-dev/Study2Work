# Study2Work Agent Bootstrap

This repository uses `.agent/AGENT_GUIDE.md` as the canonical agent context.

Before analysis, documentation, or coding, read in this order:

1. `.agent/AGENT_GUIDE.md`
2. `.agent/context/CONTEXT_INDEX.md`
3. `.agent/worklog/INDEX.md`

Root `AGENTS.md` is intentionally short so Codex-compatible tools can discover the project entry point without duplicating the full context.
